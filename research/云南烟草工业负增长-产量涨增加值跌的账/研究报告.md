# 研究报告 · 云南烟草工业负增长：产量涨、增加值跌的账

---

## 一、研究简报（写作者 1 分钟速读）

- **核心发现（一句话）**：同一份统计公报里，云南烟草工业增加值同比 **-1.9%**、卷烟产量同比 **+2.5%**——产量在涨、价值在跌，这不是需求崩塌，是"造出来的东西变便宜了"；而更关键的一层在税制里：烟叶税 20% 全额归地方政府，卷烟消费税 100% 归中央，于是"种烟"是地方的钱、"卖烟"不是地方的钱，地方保住种植面积的最优解，与全国销量下滑的现实，被这套分账规则顶在了两头。
- **3 个必须引用的事实**（含信源等级和来源链接）：
  1. 2026 年前三季度云南 GDP 24521.24 亿元、同比增长 2.2%；烟草工业增加值同比下降 1.9%，为近 10 年首次负增长；同期卷烟产量增长 2.5% `[S-2026]` [云南省统计局口径·人民网云南](https://yn.people.com.cn/n2/2026/1022/c378439-41729003.html)
  2. 2024 年烟草制品业占云南规上工业增加值 26.6%；2021-2025 年云南烟草工业增加值增速分别为 4.3%、5.8%、4.1%、1.9%、1.3%，自 2023 年起连续放缓 `[A-2026]` [第一财经](https://finance.sina.com.cn/roll/2026-10-21/doc-inivynsp6214192.shtml.md)
  3. 烟叶税税率 20%、征收于收购环节、**100% 归地方政府**；卷烟从价消费税 56%/36%（生产环节）、11%（批发环节）**100% 归中央政府**；增值税 13% 中央地方各 50%；城建税及教育费附加 12% 100% 归地方 `[A-2026]` [行业税制梳理](http://mp.weixin.qq.com/s?__biz=Mzg4NDI1NjE2Nw==&mid=2247519837&idx=1&sn=73f254c0ecda7f51ccca8d5ac654e56e)
- **最佳叙事框架**：反转框架——"你以为烟草不行了，其实是烟草卖得更多、卖得更便宜了。"
- **角度回验**：✅ 保持原角度并加强。原定切入点是"指标背离"，研究发现背离的解释有两层：表层是产品结构下移（单箱价值降），深层是税制让"保面积"成为地方的理性选择。第二层比第一层锋利得多。
- **关键风险**：卷烟产量是实物量、增加值是不变价，口径不同，不可直接相减；"结构下移"是推断而非官方结论，须用"两种解释"的方式呈现，不得断言。

- **核心观点 1**：成本三问——利润进了谁的账、成本记到了谁的未来、有没有机制让外部化的成本回流。（来源：`notebook/利润私有化成本社会化.md` 母题）

## 四、产品经理拆解板

### 4.0 方法论骨架（作者框架优先）

- **主用作者自创框架**：成本三问（利润进谁的账 / 成本记谁的未来 / 有没有回流机制）+ 责任单向转移（定义规则的一方不背代价）
- **通用框架补位**：九类话题矩阵第 1 类「政策与制度」→ 激励相容；第 5 类「数据与指标」→ 代理指标失效
- **框架选择理由（一句）**：这件事的表象是两个数打架，底层是两笔钱分给了两个层级——成本三问正好从"钱进谁的账"切进去，一刀到底。

### 4.1 五问定位

| # | 问题 | 本次答案 |
|:--:|------|------|
| Q1 | 谁的什么问题 | 签了种植合同的烟农，要在"改种别的"和"继续按合同交售"之间选；以及烟区县级财政，要在"保烟叶税"和"培育新产业"之间分配有限的土地、劳力与干部精力 |
| Q2 | 现在这条路怎么走（含真实的"凑合办法"） | 官方路径：签合同 → 按计划种植 → 分级交售 → 收购站定价 → 复烤 → 中烟按生产计划做烟 → 商业批发 → 零售户。真实走法有三层凑合：①烟农在合同面积之外"超种"，超的部分靠关系或降价进站；②等级评定是真正的定价环节，农户普遍在"初分"上下功夫（去青去杂、控水分），把等级往上抬；③县级财政把烟叶税的一部分"反哺"回去补烤烟生产（玉溪要求不少于上年烟叶税的 10%），等于用税收补贴税源。**凑合办法的核心是：所有人都在保"面积"这个数，因为面积决定收购量，收购量决定烟叶税，烟叶税决定县级财力** |
| Q3 | 卡在哪一步 | 卡在"收缩成本由谁先承担"这一步。需求端（吸烟率、零售终端）在缩，工业端还有"提结构"（涨价、调高结构）可以撑一段，烟叶收购计划是最后才调的变量——它一调，烟农收入立刻掉。所以收缩的成本不是均匀分摊的，它有顺序：终端先退 → 工业端提结构硬撑 → 收购计划最后下调 → 烟农接住 |
| Q4 | 谁在为这一步付费 | 付钱方＝烟农（合同面积与收购量决定收入，议价权最弱）＋ 县级财政（烟叶税是重要税源，产业退出后缺口无处补）；得利方＝卷烟工业（提结构保住了税利）＋ 中央财政（消费税 100% 归中央，销量下滑的影响先落在地方）；兜底方＝烟农家庭自身（无失业统计、无产业转移补偿）。三方错位极其严重：得利方在链条上游且有定价权，付钱方在链条末端且只能接受等级评定 |
| Q5 | 换个设计会怎样 | 把烟叶税从"100% 归地方"改成"中央地方分成"，同时设"烟区退出补偿"——按实际退出面积与年限给县级财政过渡性转移支付，并把补偿的一部分直补给退出的烟农。新问题：①地方失去最后一根稳定税源，短期财政缺口更大；②退出面积核验成本高，虚报风险大（历史上面积核定本就是治理难点）；③补偿标准一旦定了就难下调，形成新的刚性支出 |

### 4.2 交付物一：现状链条

```
烟农（签合同面积→按计划种植→分级交售） → 收购站（等级评定=定价权） → 复烤
   → 中烟（按生产计划投料，红塔/红云红河） → 商业批发 → 零售户（32 万家退出中） → 消费者

钱流：消费者付零售价 → 批发 → 工业 → 烟农（收购款）；其中烟叶税 20% 留县、消费税 56%/36%/11% 归中央
责任流：种植风险在烟农（天灾、等级不达标）→ 收购计划风险在县级 → 销量风险在工业与商业 → 控烟责任在中央
权力流：面积与收购计划由国家局下达 → 等级标准由收购站执行 → 价格由税制与调拨价决定 → 烟农只有交售权
```

### 4.3 交付物二：度量视角

- **这件事被什么数衡量**：烟草工业增加值（不变价，扣中间投入）、卷烟产量（实物量，亿支/万箱）、烟叶收购量（计划口径，担）、工商税利（元）
- **这个数谁定义的**：增加值由统计部门按规上工业口径核算；产量与收购量由国家烟草专卖局按计划下达并统计；税利由企业上报、行业汇总
- **它会不会被生产出来**：会，而且三个数各被一方生产。①工业端：围绕"税利"生产——靠提结构（涨价、上调高档烟占比）让税利在产量不增的情况下继续增长；②地方端：围绕"烟叶税"生产——保面积、保收购量，甚至用税收反哺种植（不少于 10%）；③终端端：围绕"进货任务"生产——压库存、把货压在店里，直到退店。**三个数各自被生产，所以它们必然打架：产量涨（保面积的结果）、增加值跌（结构下移的结果）、税利涨（提结构的结果）可以同时为真。**
- **一个必须说清的口径差**：卷烟产量是实物量，烟草工业增加值是不变价的价值量，两者不能相减。产量涨而增加值跌，只说明"单位实物创造的价值在降"，不说明"总量在萎缩"。

### 4.4 交付物三：一组真实权衡

- **约束 A**：控烟要减少消费——提高税价是最有效的手段（2015 年提税后销量降 7.8%，税占零售价从 51.7% 升到 55.7%）
- **约束 B**：烟区财政与烟农收入要稳住——烟叶税 100% 归地方，保种植面积是县级财政最直接的自救
- **为什么不能两全**：这两件事由同一套税制同时激励，且激励方向相反。中央提税 → 零售价涨 → 销量降 → 工业减产；但烟叶税归地方 → 地方扩面积 → 烟叶供给增。一端在踩刹车，一端在踩油门，中间的收购计划就是那个被两头拉扯的阀门。**不是谁不听话，是分账规则让"听话"和"保命"变成了两件事。**
- **成本最终放在哪一侧**：放在烟农与县级财政一侧。因为工业端有提结构的空间（单箱价值可调），中央财政有全国盘子可腾挪，只有烟农的收入和县级税源是刚性的、没有替代品的。

### 4.5 交付物四：反方案 + 副作用

- **替代方案**：三件事同时做——①烟叶税改中央地方分成（比如 50:50），切断"扩面积=扩税源"的直接回路；②设"烟区转型过渡基金"，按退出面积与年限给县级财政 3-5 年递减补偿；③把补偿的一部分直补烟农，与"是否完成合同面积退出"挂钩，而不是与"是否继续种烟"挂钩
- **它解决了什么**：让地方不再靠扩面积保财政，收缩的顺序从"烟农先接"改成"财政先接一段"；给了烟农一个可预期的退出路径
- **它新制造了什么**：①地方短期财政缺口更大，可能转向卖地或举债，把问题换个形式推后；②面积核验需要卫星/合同/收购三套数据交叉，治理成本高，虚报空间仍在；③过渡基金一旦设立就具备刚性，到期难退；④分成改革会削弱地方对烟叶质量的投入意愿——因为质量投入的回报本来就在烟叶税里
- **新代价落在谁头上**：落在"种得最好、最依赖烟叶"的那批核心烟农和核心烟区县头上——他们是这套体系里效率最高的一群，也是转型中损失最大的一群。这是所有"退出补偿"设计的通病：补的是退出者，不补留下的人

### 五、趋势判断
- 行业趋势：全国卷烟产量已近乎零增长（2025 年 +0.2%），行业增长完全依赖单箱价值提升；终端退店意味着"提结构"这条路的终端承载能力在下降
- 专业人士预测：卷烟工业放缓是否传导至烟叶收购计划，将直接影响烟农收入与县级财力（行业稿提出的开放问题）
- 历史周期类比：类似资源型城市的"资源诅咒"退出期——支柱产业先减速，替代产业还没长大，中间的空档由财政与就业承担
