# 研究报告 · 上海将大模型 Token 开销纳入技改支持

## 一、研究简报（写作者 1 分钟速读）

- **核心发现（一句话）**：上海《软信业"十五五"规划》首次将企业调用大模型的 Token 消耗纳入技术改造补贴支持范围——这是全国首个"按 AI 用量补贴"的政策范式，标志产业政策从"补硬件（芯片/算力基建）"转向"补软件（模型调用/数据治理）"。
- **3 个必须引用的事实**（含信源等级和来源链接）：
  1. 上海经信委印发《上海市软件和信息服务业发展"十五五"规划》，明确"探索将词元(Token)、数据治理、大模型部署及再训练等投入，纳入企业技术改造支持方向" `[S]` [上海市政府](https://www.shanghai.gov.cn/zhengce/detail?businessId=7ff732b1c470421c86e46d14c0270ead&siteId=0020)
  2. 到 2030 年上海软信业产业规模力争从 2.1 万亿元冲上 4 万亿元、产业增加值突破 1.1 万亿元 `[S]` [央视新闻](https://ysxw.cctv.cn/article.html?toc_style_id=feeds_default&item_id=14597080760361155917)
  3. 2025 年上海软信业营收 2.2 万亿元、5 年年均增速约 15%、为上海第三大支柱行业 `[A]` [上海证券报](https://finance.sina.cn/2026-08-12/detail-inimysyf4287129.d.html)
- **最佳叙事框架**：对比框架（芯片补贴/算力基建补贴旧范式 vs Token 补贴新范式）+ 问题→解决（AI 企业成本痛点→政策解法）
- **角度回验**：✅ 原始角度"按 Token 付费的补贴新范式"成立，且有政策原文背书
- **关键风险**：政策为"探索方向"非落地细则，补贴比例/申报条件未公布——文章需区分"规划方向"与"实施细则"
- **总信息来源数**：8 个
- **总字数**：待实测
