# 研究报告 · 国办发文减缓AI就业替代：第一级台阶的成本归属

---

## 一、研究简报（写作者 1 分钟速读）

- **核心发现（一句话）**：政策要"减缓 AI 就业替代"，措辞里藏着一句最能落地的话——"鼓励企业探索建立失业缓冲期制度"；而企业端的数据已经在说，被替代的不是一个岗位，是"新人练手的那一级台阶"，过去这级台阶的成本由新人用低工资自付，现在企业不需要它了，这笔账就被推出了企业边界。
- **3 个必须引用的事实**（含信源等级和来源链接）：
  1. 国办《关于适应人工智能技术发展助力构建就业友好型发展方式的意见》提出 6 方面 18 项任务，明确"有效减缓人工智能应用就业替代影响""建立人工智能应用就业风险评估机制""鼓励企业探索建立失业缓冲期制度" `[S-2026]` [中国政府网](https://www.gov.cn/yaowen/liebiao/202610/content_7084113.htm)
  2. Anthropic 内部研究：技术部门新招员工中初级岗占比从 27% 降至 9%，初级员工占比从 21% 降至 14%（相对降幅约 33%）；截至 2026 年 8 月，Agent 与人类工时比 6:1，研究部门 19:1 `[A-2026]` [新浪财经](https://finance.sina.cn/2026-10-20/detail-inivwcmp5836679.d.html)
  3. 2026 年 9 月全国城镇 16-24 岁劳动力失业率 18%，25-29 岁 7.4%，30-59 岁 3.9%；2026 届高校毕业生预计 1270 万人，再创新高 `[S-2026]` [国家统计局数据·财联社](https://www.cls.cn/detail/2510556)
- **最佳叙事框架**：反转框架——"你以为 AI 替代的是老员工，其实先被抽走的是新人进门的那级台阶。"
- **角度回验**：✅ 保持原角度。研究发现"培养成本"这一层比预想的更硬：贝克尔 1964 年的算术题已经把机制讲完了，Anthropic 的数据只是让它失效的那一半。
- **关键风险**：Anthropic 是单一公司样本，其招聘门槛本来就偏资深（LinkedIn 样本显示工程师加入前经验中位数 12.2 年），不可外推为全行业；行文必须标注样本边界。
- **总信息来源数**：22 个
- **总字数**：6842 字（达标）

## 四、产品经理拆解板

### 4.0 方法论骨架（作者框架优先）

- **主用作者自创框架**：成本三问（利润进谁的账 / 成本记谁的未来 / 有没有回流机制）+ 三笔账（得利方 / 付钱方 / 兜底方）
- **通用框架补位**：九类话题矩阵第 8 类「组织与劳动」→ 岗位设计与考核 + 外包与责任边界；第 5 类「数据与指标」→ 代理指标失效
- **框架选择理由（一句）**：这个话题的痛点不在"AI 强不强"，在"效率收益与培养成本被分到了两个不同的账本上"，成本三问一刀就能切开。

| Q1 | 谁的什么问题 | 22 岁刚毕业、想进技术岗的人，要在"没有项目经验"的前提下拿到第一份能积累判断力的工作；以及带团队的中层，要在一群 Agent 和一个空着的初级编制之间，决定把活派给谁 |
| Q2 | 现在这条路怎么走（含真实的"凑合办法"） | 官方路径：投简历 → 笔试面试 → 入职 → 头两年低薪干活顺便学。真实走法已经变形：应届生先刷"AI 项目作品集"（自己用 Agent 做几个 demo），再走实习转正；企业这边把原本的初级岗拆成"实习 + 外包 + Agent"，用实习生承担原来初级工程师的活，用 Agent 承担原来实习生的活；实在招不到合适的人，就干脆把编制挂在中级，让老人多干。凑合办法的核心是：**用"实习"和"外包"两个筐，接住原来"初级岗"这个筐里的东西** |
| Q3 | 卡在哪一步 | 卡在"谁付前 18 个月的培养成本"这一步。企业算的是单人产出，社会算的是人才存量，两本账的周期不同（企业按财年，人才成长按 3-5 年），所以谁都不愿意在自己的账期内认这笔支出 |
| Q4 | 谁在为这一步付费 | 付钱方＝新人（以低起薪、长实习期、无社保的实习岗支付）；得利方＝采用 AI 的企业（效率提升即时入账）；兜底方＝财政与家庭（失业期生活费、再培训、延缓就业的考研考公）。三方错位：得利方不付钱，付钱方不兜底 |
| Q5 | 换个设计会怎样 | 把"培养"从企业自愿行为改成可计价的采购：企业每替代一个初级岗，按人头向公共实训基金缴一笔"梯队费"，基金反向后补贴招应届并完成带教的企业。新问题：会催生"只为拿补贴而招、带教走形式"的套利，且中小企业的现金流扛不住前置缴费 |

### 4.2 交付物一：现状链条

```
应届生投递 → 企业筛选（门槛已上移到"有作品/有实习"） → 入职头两年低薪干活（=自付学费）
   → AI 接手"规则清晰、执行性强"的那部分活 → 企业不再需要"边干边学"的人
   → 初级编制收缩 → 培养职能被推出企业边界 → 落到家庭、财政、公共实训

钱流：新人以低工资支付学费 → 企业获得超额产出 → 效率收益留在企业损益表
责任流：企业原本承担"带人"责任 → AI 替代后责任消失（无合同、无罚则）→ 最终由财政再培训与家庭储蓄兜底
权力流：招聘门槛与岗位定义权在企业 → 统计口径与评估权在主管部门 → 新人只有投递权
```

### 4.3 交付物二：度量视角

- **这件事被什么数衡量**：企业端是"人均产出/人力成本比"，宏观端是"16-24 岁城镇调查失业率"与"高校毕业生就业落实率"
- **这个数谁定义的**：企业端的口径由 HR 与财务共同定义（分子是营收或交付量，分母是在册人数）；宏观端由国家统计局定义（城镇、调查失业、16-24 岁分档）
- **它会不会被生产出来**：会，而且已经在生产。①企业端：把初级活外包给供应商后，人均产出立刻变好看，因为分母里没有那些人了；②宏观端：失业率只统计"在找工作的人"，继续读书、考公、回家待着的人不进分子也不进分母，替代的真实规模会被这套口径系统性低估。**这正是"指标即生产任务"的典型现场——指标一旦成为考核目标，被考核方会围绕指标的形状重组自己，而不是围绕问题本身。**
- **补充**：政策提出"建立人工智能应用就业风险评估机制"，等于承认这个数现在还不存在。一个还没被定义的数，最容易被定义成"看起来不严重"的形状。

### 4.4 交付物三：一组真实权衡

- **约束 A**：AI 提效要求企业把"规则清晰、执行性强"的环节交给模型，否则在成本上打不过同行——这是竞争约束，不这么做就出局
- **约束 B**：人才培养要求企业保留"低效但必要"的初级岗位，让新人在真实任务里长判断力——这是梯队约束，不做就断代
- **为什么不能两全**：两件事争夺的是同一份预算和同一个编制。初级岗的价值恰恰在于"产出略高于工资"这个薄薄的差额（贝克尔算术题），AI 一进来，这个差额直接变成负数——不是企业变坏了，是这道算术题的解没了
- **成本最终放在哪一侧**：放在新人一侧。因为企业有退出权（不招就行），新人没有议价权（第一份工作只能有一个）。政策能做的只是把退出变慢一点，不能把退出变没有

### 4.5 交付物四：反方案 + 副作用

- **替代方案**：把"失业缓冲期"从企业自愿改成"替代即触发"的强制排期——企业在大规模上线替代性 AI 前须报备受影响岗位清单，缓冲期内该岗位编制不得核销，且须把被替代者的任务转为"带教 + 验收 Agent 输出"，同时按人头向公共实训基金缴费
- **它解决了什么**：把培养成本从"新人自付"改成"效率收益方分摊"，且给了一个可核查的动作（编制是否核销、带教是否有记录），解决了"减缓替代"没有抓手的问题
- **它新制造了什么**：①报备制会催生"化整为零"——把替代拆成几十个小项目规避阈值；②"带教 + 验收"容易被做成形式，变成新的填表任务；③前置缴费对中小企业现金流不友好，可能反而加快它们放弃自建团队、全面外包
- **新代价落在谁头上**：落在中小企业和它们的现有员工头上——大企业有合规团队可以设计报备路径，中小企业只能选择"不招"或"全外包"，这两种选择都不产生培养
