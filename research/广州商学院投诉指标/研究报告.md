# 研究报告 · 广州商学院投诉指标：700 单申诉是怎么生产出来的

## 一、事件事实核

### 1.4 各方立场（公开信息）

- **校方**：未公开回应。媒体提出的四个问题未获答复——租金调整依据是什么？投诉指标是否属实？是否已经叫停？后续快递服务如何保障？
- **内部工作人员**：向记者反映商管部门"未通过协商谈判解决问题，转而采取批量申诉方式施压"。
- **学生**：多数认为刷投诉"没必要"，参与意愿低；关注点在取件不便、车辆出入受限。
- **快递侧**：网点撤出后，700 单投诉落到末端网点与快递员。
- **评论界**：集中在三点——涨租是商业自由但手段越界；扣绩效涉嫌违反劳动法；组织批量虚假投诉涉嫌侵权。

### 1.5 必须回避的表述

- 不认定"虚假投诉"为法律事实（校方未回应，投诉内容是否虚构无公开证据，只能用"被组织批量发起的投诉"）；
- 不评价该校办学质量、不扩大到民办教育整体；
- 不对具体个人（商管部门负责人、辅导员）作人身评价；
- 不使用"无耻""耍无赖"等媒体评论用语（本号不跟情绪，跟机制）。

## 二、制度与指标机制

### 2.1 邮政申诉通道的设计假设

邮政业消费者申诉受理机构的工作前提是：**每一单申诉，对应一个真实消费者的一次真实不满**。这条假设支撑三件事——

1. **成本极低但非零**：对申诉人几乎零成本（一次点击），但受理端有人力成本、被申诉企业有核查与答复成本；
2. **读数有效**：申诉量被用作快递企业服务质量的核心考核输入（各快递总部对网点与快递员的罚款，直接挂在申诉率上）；
3. **公信力来自稀缺性**：通道的价值建立在"能进来的都是真问题"，一旦可以被批量灌入，读数与公信力同时失效。

### 2.2 指标被"生产"的三个条件（本案全部满足）

| 条件 | 本案表现 |
|---|---|
| 填报成本低于真实成本 | 一次申诉点击 ≈ 0 元，而真实不满需要经历延误、丢失、损毁 |
| 生产者与受益者分离 | 生产投诉的是教师（被摊派），受益的是校方（租金谈判筹码），承担罚款的是快递员 |
| 指标可被单方计量 | 每人 6 单、未完成扣绩效——指标被量化到人、按日结算 |

### 2.3 指标的传导链

```
校方涨租（场地定价权）
  → 网点撤出（成本无法覆盖）
    → 学生取件不便（服务中断）
      → 校方组织投诉（指标摊派）
        → 申诉量激增（读数失真）
          → 快递总部考核（申诉率上升）
            → 网点与快递员罚款（500 元/单）
              → 网点更不愿回场 / 服务质量进一步下滑
```

这是一个**负反馈被误当作正反馈使用**的回路：校方以为投诉量上升会增加快递企业的回场压力，实际结果是末端成本上升、服务意愿下降，回到校内的动机更弱。

## 四、产品经理拆解板

### 4.1 方法论骨架

主框架取「数据与指标 · 代理指标失效（古德哈特）」，辅助框架取「组织与劳动 · 岗位设计与考核」。

选择理由：这个话题有两层。表层是"高校用投诉通道施压"（治理问题），里层是"一条以真实性为前提的指标被批量生产"（指标机制问题）。前者只能骂，后者能拆。辅助框架用来处理第二次成本转移——教师被征用为投诉产能，属岗位职责与考核边界的典型越界。两个框架，各管一层，不引入第三个。

### 4.2 五问定位

| # | 问题 | 本案答案 |
|:--:|---|---|
| Q1 | 谁的什么问题 | 三方各有各的问题：**校方商管部门**要完成"场地租金收益最大化"；**近 3 万在校生**要完成"不出校门取到快递"；**末端网点与快递员**要完成"在派费 1 元/单的成本结构下不亏本"。三方目标在同一块场地上冲突 |
| Q2 | 现在这条路怎么走 | 完整路径：校方涨租 → 网点核算发现租金超过可承受固定成本 → 全线撤出 → 学生取件不便、车辆出入受限 → 校方不回到谈判桌，改在内部行政群摊派申诉指标（每人每天 6 单、未完成扣绩效）→ 教职工在邮政申诉平台批量提交 → 快递总部考核端申诉率飙升 → 罚款落到网点与快递员（500 元/单）。**真实的"凑合办法"**：学生转向校外代收点或自行到校外取件；网点改用校外场地；教师用自己的账号分散提交以规避平台风控 |
| Q3 | 卡在哪一步 | 卡在**场地定价没有第二种结算方式**。校内场地是垄断供给（一个校园、一个入口、一套准入），租金由校方单方定价；末端派费约 1 元/单，租金是最大固定成本。只要租金只能以"年租"形式结算，涨价就必然挤出网点——不存在"涨租但网点还在"的中间态 |
| Q4 | 谁在为这一步付费 | 四层：①快递员/网点（每单投诉罚 500 元，700 单量级的罚款）；②教师（被摊派指标，未完成扣绩效）；③学生（取件成本上升、时间成本）；④公共资源（申诉受理端的人力被占用，真实消费者的通道被挤占）。收益方只有一个：校方的场地租金 |
| Q5 | 换个设计会怎样 | 若改成"零租金 + 按件服务费 + 准入招标 + 合同罚则"，租金冲突消失，但会带来三个新问题（见 4.6） |

### 4.3 交付物一：现状链条

```
钱流（向下沉）
校方（场地所有者）──涨租──▶ 快递网点（承租方）──撤出──▶ 学生（使用者）
    ▲                                                        │
    │  租金收益                                              │ 取件不便
    │                                                        ▼
    └──── 投诉量作为谈判筹码 ◀── 商管部门摊派 ◀── 学生不满外溢
                                    │
                              教职工（每人每天 6 单）
                                    │
                                    ▼
                            邮政申诉平台 ──▶ 快递总部考核 ──▶ 网点/快递员（500 元/单罚款）
```

**每一环的角色表**

| 环节 | 谁在做 | 拿到什么 | 付出什么 |
|---|---|---|---|
| 涨租 | 校方商管中心 | 场地租金收益（年租数十万元量级） | 服务中断的舆情与治理成本 |
| 撤出 | 快递网点 | 止损 | 校园市场份额、既有投入 |
| 取件 | 学生 | 快递服务（改到校外） | 时间、交通、代收费用 |
| 摊派 | 商管部门 → 辅导员/行政 | 700 单投诉量 | 教师绩效被扣、本职工作时间被占用 |
| 提交 | 教职工 | 完成考核 | 个人账号被用于非本人诉求的申诉 |
| 受理 | 邮政申诉机构 | 申诉工单 | 人力被占用，真实申诉的排队时间变长 |
| 考核 | 快递总部 | 服务质量读数 | 读数失真 |
| 罚款 | 网点/快递员 | 无 | 500 元/单，直接扣收入 |

**三条流的方向**：
- 钱：租金向上（校方收），罚款向下（快递员出），中间没有一分钱流向"服务改善"。
- 责任：服务中断的责任从"定价方"转移到"退出方"，再转移到"被执行方"。
- 权力：准入权、定价权、指标分配权，三项全部集中在同一个部门手里。**权力集中而成本分散，这就是全部问题的结构。**

### 4.4 交付物二：度量视角

这件事被一个数字衡量：**邮政申诉量**。

- **它测什么**：设计上测"消费者真实不满的强度"。它是快递行业服务质量考核的核心输入，直接挂在总部对网点的罚则上。
- **谁定义**：申诉的受理口径由邮政管理部门定义；但"什么算一次有效申诉"的判定权，在受理端与企业核查端的组合里。本案的关键不在定义，在**入口**——申诉的提交成本是否被限制。
- **会不会被生产**：本案给出了完整答案——**会，而且是按人头、按日、按绩效结算地生产**。生产条件只有一条：填报成本（一次点击）远低于真实不满的成本（延误、丢失、损毁），且填报人既不是受益者、也不承担读数失真的后果。

**读数失真的具体后果**：

| 后果 | 机制 |
|---|---|
| 罚款错配 | 700 单投诉对应的罚款约落在末端（按 500 元/单计），而真实责任方是定价方 |
| 通道贬值 | 申诉量与真实不满脱钩后，这个指标对监管、对企业、对消费者同时失去参考价值 |
| 挤出效应 | 受理端人力被批量工单占用，真实申诉的处理时长上升 |
| 逆向激励 | 网点发现"回场=更高租金+更高罚款"，回场动机进一步下降——校方想要的结果与指标指向相反 |

**这是古德哈特定律的极端形态**：通常的表现是"指标被优化"（真实努力被形式动作替代），本案是"指标被制造"（分子直接由组织生产）。两者只差一个条件——填报成本是否接近于零。

### 4.5 交付物三：真实权衡

**一对不能两全的约束：**

- 约束 A：**场地资产要变现**。校内场地是稀缺资源，学校作为资产所有者有合理动机把它变成经营性收入；一块一年几十万元租金的场地，对民办高校的预算不是小数目。
- 约束 B：**校园服务要可及**。近 3 万人、每天六七千票快递，末端派费约 1 元/单，租金是最大固定成本。租金一旦超过网点可承受线，网点只能退出，服务可及性归零。

**为什么不能两全**：因为 A 和 B 争的是同一块钱——网点的毛利。派费 1 元/单是行业给定的收入上限，租金是唯一可被单方调整的成本项。校方每多收一元租金，网点就少一元生存空间。**在"年租"这一种结算方式下，两者是零和的，没有中间值。**

**本案的选择**：校方选了 A，并且不接受 B 的后果（服务中断），于是用投诉指标去强行回收 B。这是**用一个不承担成本的工具，去修补一个由自己定价造成的缺口**。

**成本最终放在哪一侧**：放在最没有议价能力的三端——快递员（罚款）、教师（绩效）、学生（时间）。而定价权、准入权、指标分配权三项权力，全部留在同一个部门手里。**权力与成本的分布完全相反，这就是判断这件事性质的唯一依据，不需要道德形容词。**

### 4.6 交付物四：反方案 + 副作用

**替代方案：把"场地租赁"换成"服务采购 + 准入招标 + 合同罚则"三件套。**

1. **零租金或低租金 + 按件服务费**：学校不收年租，改按实际派件量收取极低的场地服务费（例如 0.05-0.1 元/件），让网点成本随业务量浮动，而不是固定支出。
2. **准入招标 + 服务标准（SLA）**：把"谁能进校"和"要达到什么服务标准"写进招标文件，用派件时效、投诉率、破損率作为评标与续约条件。
3. **合同罚则替代申诉通道**：违约就用合同罚款、扣减服务费、终止合作，**不再借用公共申诉通道**。

**它解决了什么**：把冲突从"公共通道"拉回"合同桌面"。租金与服务标准同时被写进合同，双方各有可执行的救济手段；申诉通道恢复只承载真实不满，读数重新有效。

**它新制造了什么**：

1. **服务费进学校预算，需要有人买单**。租金收入变成服务支出（或收入大幅减少），缺口只能由学费或财政补，或者压低其他支出。**这是一个真实的转移，不是免费的改进。**
2. **招标会引入"低价中标—再涨价"的循环**。压价进来的运营商，第二年要么涨价、要么降服务，学校又要重新招标。招标次数上升，管理成本上升。
3. **SLA 需要"满意度"这类软指标，又回到"指标怎么定"的老问题**。投诉率一旦写进 SLA，同样面临被生产的风险——只是这次生产方变成了企业自己（例如把小额投诉私下补偿掉，不让它进系统）。**换了主体，没换机制。**
4. **学校仍可用"安全、秩序、车辆管理"限制准入**。这些理由天然正当，且难以被合同约束，实质是保留了单方否决权。

**新代价落在谁头上**：主要落在**学校的运营预算**与**学生的服务稳定性**上。前者要接受"场地不再是创收项"，后者要承受招标切换期的服务波动。相比之下，现状是把代价放在快递员、教师、学生三端——**这就是为什么现状能维持：因为承担代价的人，没有定价权。**

### 4.7 术语预算（正文 ≤5 个，逐个配人话）
