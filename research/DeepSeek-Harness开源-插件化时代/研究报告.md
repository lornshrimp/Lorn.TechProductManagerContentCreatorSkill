# 研究报告 · DeepSeek Harness 开源：AI 应用进入"插件化"时代

---

## 一、研究简报（写作者 1 分钟速读）

- **核心发现（一句话）**：8 月 13 日晚，DeepSeek 发布首款 Agent 产品 DeepSeek Harness v0.1 开发者预览版，MIT 协议全开源——"Model + Harness = Agent"，一切皆插件，直接对标 OpenAI Codex 和 Claude Code，这是 DeepSeek 从"卖模型"切入"模型上层开发者生态"的战略转向。
- **3 个必须引用的事实**（含信源等级和来源链接）：
  1. DeepSeek Harness v0.1 于 8 月 13 日晚发布，MIT 开源协议开放全部源码，基于 Cordis 插件元框架构建，"一切皆插件" `[A-2026]` [来源](https://www.163.com/dy/article/L49SBK200534A4SC.html)
  2. Harness 定位"Model + Harness = Agent"：模型负责思考推理，Harness 承担工具调用/任务规划/执行调度等全部工程化工作，聚焦代码智能体赛道，对标 OpenAI Codex 和 Claude Code `[A-2026]` [来源](https://new.qq.com/rain/a/20260814A06AVN00?refer=cp_1009)
  3. 默认部署含 159 个插件，GitHub 已获 72.6k stars / 6.2k forks；四类运行模式（标准/PTC/极简/创造），支持项目管理、长任务协作、多 Agent 编排、上下文管理、联网搜索和 Skill `[A-2026]` [来源](https://rits.shanghai.nyu.edu/ai/deepseek-harness-cordis-everything-is-a-plugin)
- **最佳叙事框架**：时间线框架 + 对比框架 — 从"DeepSeek 发布产品"到"为什么 Harness 值得关注"，用产品视角拆解"一切皆插件"
- **角度回验**：✅ 原始角度"AI 应用进入插件化时代"成立；建议补充与 Claude Code/OpenAI 的生态对比
- **关键风险**：v0.1 仍为早期预览版，勿过度承诺"替代 Claude Code"；技术细节需与官方文档核对
