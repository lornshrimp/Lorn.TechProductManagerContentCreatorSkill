# 研究报告 · 烧烤店被查 15 次停业——116 件投诉与守法者的成本账

---

## 一、作者观点底座（写作筋骨，网上观点当靶子）

本选题落在作者常驻议题「利润私有化、成本社会化」母题的**特例分支——守法成本社会化**（详见 notebook/利润私有化成本社会化.md「拾柴者冻毙」小节）。核心判断链条：

1. **账本论三问（统一骨架）**：一笔账的收益进了谁的账？成本记到了谁的未来？有没有机制让外部化的成本回流？（notebook/利润私有化成本社会化.md）
2. **守法成本社会化的镜像**：成本社会化不只发生在违规者身上——当执法缺位/失当，守法者的合规成本同样被外部化。胖东来式企业自掏腰包补足劳动成本，却要独自面对违法压价者的竞争，「为众人拾柴者，必将冻毙于风雪中」（notebook/社保与劳动制度批判.md 09-07 修订）。本选题是这一判断在**小微商户 + 行政执法**场景的平移：一家本可合规经营的小店，被检查频次本身逼到关门，等于被制度环境「冻毙」。
3. **考核结构的激励（利益输送闭环·制度维度）**：作者指出，制度不只为强者省钱，还替自己得利——「税费当期入库，负责人短期政绩兑现，至于将来如何，我走后哪管洪水滔天」（notebook/社保与劳动制度批判.md 09-10 二次深化）。本选题的「件数 / 结案率」考核，正是这一短期政绩结构的翻版。
4. **「只打老虎不打苍蝇」机制**：选择性执法的根源不是执法者偷懒，是举证 / 触发结构让日常问题浮不出水面（notebook/社保与劳动制度批判.md 09-10 药方顺序）。本选题里「116 件投诉来自同一人、538 件投诉覆盖 60+ 家店」正暴露触发结构失衡。
5. **金句弹药（必须落点 ≥1）**：
   - 「举报是权利，受理是义务，但『件数』从来不是成绩」
   - 「没人能扛住大盖帽一天来三趟」
   - 「守法成本高到一定程度，守法就成了一种惩罚」
   - 「把执法频次当政绩，守法的人就成了耗材」
   - 「嘴上喊的是主义，心里想的全是生意」（利益输送闭环）
   - 「为众人拾柴者，必将冻毙于风雪中」（公开安全表述）

> 红线：本选题**不可**写「某部门报复」的事实性指控，也**不可**对投诉人动机做道德审判——事实边界是张先生「怀疑」、官方称动机「不清楚」，二者无因果证据。靶子是**机制与考核结构**，不是具体主体的恶意。

### [讨论]
- #1 正方（须正面承认）：12345「接诉即办」是制度善意；公民举报是法定权利；食安、消防检查天然正当；官方已认「个别不规范」并列出已核实违规（情绪：克制 / 立场：不树稻草人）
- #2 反方（作者机制拆解）：当考核奖励「件数 / 结案率」而非「真实问题解决率」，系统会自发产生「可重复触发的检查」；116 同人投诉 + 538 件覆盖 60+ 店 = 触发结构失衡（情绪：冷峻 / 立场：机制批判）
- #3 平行对照：张先生另向省文旅厅举报「菏泽古船出土元代青花杯遗失」并报案，二者时间接近；但**无证据**显示高频检查与文物举报有因果，张先生仅「怀疑」，官方称动机「不清楚」（情绪：克制 / 立场：严守事实边界）

### [展望]
- #1 考核应从「件数 / 结案率」改为「问题解决率 / 不重复触发率」；「接诉即办」应从「接诉」走向「办结且不重复」（情绪：建设性 / 立场：药方）
- #2 观察点：山东 21 条举措落地效果、司法行政对「不规范」的后续处理、同类高频投诉的触发阈值是否设限（情绪：观望 / 立场：看执行）

## 四、反方论点（须正面回应，不得树稻草人）

1. **「市民举报天经地义，店铺有问题就该查。」** → 认：举报是法定权利，12345「接诉即办」是制度善意；该店确有违建、食安、油烟等可核实违规，执法有正当起点。
2. **「5 个部门各查各的，本来就是分头履职，谈不上过度。」** → 认：分头履职合情合理；但国办 2025-01 文件已明令「不得重复查、多头查、扫码进」，山东 21 条亦落地，说明「分头」本应有边界。
3. **「高频投诉说明群众意见大，检查多是回应民意。」** → 认：民意要回应；但 116 件同人、538 件覆盖 60+ 店的触发结构，说明「回应」已被「触发机制」绑架，件数不等于民意的真实密度。
4. **「老板关门是他自己经营不善 / 真有违规。」** → 部分认：确有违规应整改；但把「可现场整改的小问题」与「15 次上门逼停」混为一谈，就漏算了「守法成本」——频次本身是有价的。
