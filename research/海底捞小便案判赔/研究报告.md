# 研究报告 · 海底捞「小便案」索赔 2300 万判赔 220 万：商誉的司法定价

## 一、事件事实核

### 1.1 时间线

| 时间 | 节点 |
|---|---|
| 2025-02 | 唐某、吴某（事发时均 17 周岁）在某火锅品牌门店包间用餐期间，为寻求刺激先后站上餐桌向火锅内小便并拍摄视频；后吴某在网络上发布视频，经快速传播引发消费者对该品牌门店卫生环境与食品安全的广泛质疑 |
| 2025-02 起 | 涉事门店更换所有餐具、锅具并全面清洗消毒；全额退还受影响时段堂食顾客餐费；按消费金额十倍给予补偿 |
| 2025-03 | 四川某餐饮管理公司、上海某餐饮管理公司作为该品牌商标授权使用方，向上海市黄浦区人民法院提起诉讼，诉请赔偿经营损失、商誉损失等共计 2300 余万元 |
| 一审 | 黄浦区法院由一名人民陪审员与两名法官组成三人合议庭审理；判决唐某父母、吴某父母赔偿餐具损耗费和清洗消毒费 13 万元、经营损失和商誉损失 200 万元、维权开支 7 万元，合计 220 万元；在指定报刊刊登道歉声明 |
| 一审后 | 双方当事人均未上诉，判决已生效 |
| 2026-10-23 | 最高人民法院发布第三批人民陪审员参审典型案例，本案细节对外披露 |

### 1.2 判决构成（核心算术）

| 项 | 金额 | 性质 |
|---|--:|---|
| 餐具损耗费 + 清洗消毒费 | 13 万元 | 直接财产损失（必要支出） |
| 经营损失 + 商誉损失 | 200 万元 | 可证经营下滑 + 商誉贬损 |
| 维权开支 | 7 万元 | 律师费、取证费等合理必要部分 |
| **判决合计** | **220 万元** | — |
| 诉请金额 | 2300 余万元 | — |
| **差额** | **约 2080 万元** | 主要为"退一赔十"的补偿支出 |

> **差额口径说明**：2300 余万 − 220 万 = 2080 余万。媒体报道未逐项披露 2300 万的构成，只明确"按消费金额十倍补偿"是主要争议部分。本文的表述是"约 2080 万元，主要为十倍补偿支出"，不写成精确的分解表。

### 1.3 法院与陪审员的核心意见（判决定性的关键）

人民陪审员在合议时提出两条意见，构成本案真正的裁判要点：

1. **退款已起到合理补偿、商誉修复的作用**。餐饮公司向受影响时段消费者全额退款，已属合理补偿；再按餐费金额十倍补偿，属于该公司的**自主商业决策**。
2. **以十倍补偿为基础向被告索赔 2300 万元不合情理**。

此外，陪审员还核实了监护人对未成年人的日常教育、交友范围与网络行为监管情况，重点包括"对未成年人深夜结伴外出饮酒就餐是否知情、有无及时劝阻约束"，完整还原监护人"重物质供给、轻品德培育"的客观事实，为合议庭认定侵权责任夯实基础。

### 1.4 责任分配要点

| 要点 | 内容 |
|---|---|
| 侵权性质 | 共同侵权（两人先后实施、互拍视频），构成财产侵权与名誉侵权 |
| 责任主体 | 限制民事行为能力人致害，由监护人承担侵权责任；本人有财产的先从本人财产支付，不足部分由父母补足（民法典第 1188 条） |
| 道歉 | 两名未成年人本人与父母共同登报道歉，对未成年人身份作隐私保护处理 |
| 行政责任 | 警方已对两人作出行政拘留决定；因满十六不满十八且属初次，拘留决定作出但不送所执行 |
| 年龄认定 | 17 周岁已具备是非辨别能力，"未满 18 周岁不是肆意妄为的护身符" |

### 1.5 必须回避的表述

- 不评价量刑轻重（"判多了/判少了"）；
- 不消费案件细节、不渲染行为过程；
- 对未成年人使用报道已用的化名口径（唐某、吴某），不加任何可识别信息；
- 不对企业索赔动机作道德评判（"讹人""碰瓷"），只分析索赔构成的合法性边界；
- 不把"十倍补偿"写成"营销作秀"——它是企业的自主商业决策，这一表述本身来自陪审员意见，属中性描述。

## 二、成本结构与法律框架

### 2.1 三段成本的性质差异

这是全案最重要的一张表。220 万不是"打折后的 2300 万"，而是**三段性质不同的成本之和**。

| 成本段 | 金额 | 是否"不得不花" | 是否可向侵权人转嫁 |
|---|--:|---|---|
| 餐具损耗 + 清洗消毒 | 13 万 | 是（不换不洗无法继续营业） | ✅ 可 |
| 经营损失 + 商誉损失 | 200 万 | 是（客流下降是客观结果） | ✅ 可（以可证为限） |
| 维权开支 | 7 万 | 是（诉讼必需） | ✅ 可（合理必要部分） |
| 退一赔十的补偿支出 | 约 2080 万 | **否**（企业为挽回人心主动加码） | ❌ 不可 |

**这条分界线就是本案的裁判核心**：赔偿只覆盖"不得不花"的钱，不覆盖"为了挽回人心主动多花"的钱。前者是侵权造成的必要后果，后者是企业自己的商业判断。

### 2.2 为什么"十倍补偿"不能转嫁

三个理由，法院与陪审员意见指向的是第二条与第三条：

1. **因果关系**：十倍补偿不是侵权行为的必然结果，而是企业在退款之外自愿增加的给付。同一侵权行为下，企业可以选择只退款，也可以选择退一赔十，选择权在企业。
2. **可预见性**：侵权人（两名 17 岁未成年人及其监护人）无法预见企业会采用何种赔付标准。若按企业自定标准赔偿，等于让侵权人承担他人单方设定的责任上限。
3. **激励效应**：若十倍补偿可全额转嫁，企业就有动机把危机公关的支出做成"可索赔损失"，赔付标准越高、索赔金额越大，最终由侵权人买单。这会形成"越赔越告"的逆向激励。

### 2.3 商誉损失为什么是 200 万

判决没有披露 200 万的测算过程，但可以从三个方向理解它的量级：

- **时间维度**：影响集中在视频传播后的特定时段，不是全年；
- **范围维度**：限于涉事门店及其辐射区域，不是全品牌；
- **可证维度**：以客流量、营业额的同期对比为据，需要企业举证，不能只凭"品牌价值×影响系数"估算。

**方法论启示**：司法对商誉损失的计量，走的是"可观测的经营数据 + 必要补救支出"，而不是"品牌评估值折损"。这是两种完全不同的算法，前者有账可查，后者只能靠评估报告。

**写作立论**：这份判决真正有价值的地方，不是"220 万够不够"，而是它划出了一条**企业自主决策成本的边界**——你可以为了挽回人心赔十倍，但这份加码不能转嫁给侵权人。换句话说：**善意可以是企业的选择，但不能成为他人的账单。**

这条边界比金额重要得多。它同时约束了两端：约束企业（不能把公关预算外部化），也约束司法（不能因为企业"受害者"身份就全额支持诉请）。

**与作者三观的接口**：这是「定价权=成本归属权」的反向应用。通常我们批评"有定价权的人把成本推给别人"，这次是司法把这个动作挡了回去——**它没有让有定价权的一方，把自己的加码变成对方的负债。** 这是少见的、机制站在成本归属正确一侧的案例。

## 四、产品经理拆解板

### 4.1 方法论骨架

主框架取「商业与公司 · 单位经济模型（UE）」，辅助框架取「消费与定价 · 支付意愿与信息租金」。

选择理由：本案的争点表面是法律责任，实质是**一次成本核算的边界划定**——哪些支出算"经营的必要成本"，哪些算"自主的增量投入"。UE 框架正好能把 2300 万拆成四段性质不同的成本，看出哪一段被砍、为什么被砍。辅助框架用来解释"商誉"这个东西为什么难定价：它没有对应的成本科目，只有市场的支付意愿。两个框架，各管一段。

### 4.2 五问定位

| # | 问题 | 本案答案 |
|:--:|---|---|
| Q1 | 谁的什么问题 | 三方：**餐饮企业**要完成"把一次公共卫生事件的损失收回来"；**两个 17 岁孩子的家庭**要面对"一次恶作剧变成 220 万债务"；**同店其他消费者**要完成"知道自己用的餐具是否受污染"。三方在同一个赔偿数额上争夺 |
| Q2 | 现在这条路怎么走 | 完整路径：行为发生（包间、17 岁、拍视频）→ 视频上网传播 → 消费者抵触、客流下降 → 门店补救（换全部餐具锅具 13 万、全面消毒、全额退费、按消费金额十倍补偿）→ 起诉索赔 2300 余万 → 法院核算三段成本（13+200+7）→ 判 220 万 → 监护人赔付 + 登报道歉。**真实的"凑合办法"**：企业用"退一赔十"替代"逐一沟通"来快速止损——这是危机公关的常规做法，用钱换时间；消费者用"不再去"替代"追责"；侵权人家庭只能接受判决（未上诉） |
| Q3 | 卡在哪一步 | 卡在**"商誉损失"没有成本科目**。餐具可以数、消毒可以报价、律师费有发票，唯独"品牌受多大伤"没有账面依据。企业的解决办法是把"十倍补偿"当成商誉损失的代理，但这一步跨过了因果链——补偿是企业选的，不是侵权造成的 |
| Q4 | 谁在为这一步付费 | 判决层：220 万落在两个 17 岁家庭（监护人）。未判层：约 2080 万的十倍补偿留在企业账上，由股东承担。第三层：同店消费者的知情权救济没有被单独计价，他们可以另行主张（本案未涉及） |
| Q5 | 换个设计会怎样 | 若建立"商誉损失可赔上限公式"（受影响门店同期营业额跌幅 × 影响天数 + 必要补救支出），边界会更清晰，但会带来四个新问题（见 4.6） |

### 4.3 交付物一：现状链条

```
行为（17 岁 / 包间 / 拍视频）
  → 传播（视频上网，二次扩散）
    → 市场反应（消费者抵触、客流下降、社会评价降低）
      → 企业补救（换餐具 13 万 + 消毒 + 全额退费 + 十倍补偿 ≈ 2080 万）
        → 起诉（索赔 2300 余万）
          → 司法核算（13 + 200 + 7 = 220 万）
            → 赔付（监护人承担）+ 登报道歉
```

| 环节 | 谁在做 | 拿到什么 | 付出什么 |
|---|---|---|---|
| 行为 | 两名 17 岁未成年人 | 刺激、视频素材 | 行政拘留决定（未执行）、民事赔偿 |
| 传播 | 其中一人上传，平台扩散 | 流量 | — |
| 市场反应 | 消费者 | 用脚投票 | 对该品牌的信任 |
| 补救 | 涉事门店/品牌方 | 止损、商誉修复 | 13 万直接支出 + 退费 + 约 2080 万十倍补偿 |
| 起诉 | 两家商标授权使用方 | 索赔主张 | 诉讼成本（7 万可获赔） |
| 核算 | 法院 + 人民陪审员 | 一个可执行的数额 | 裁量压力 |
| 赔付 | 两家庭（监护人） | 无 | 220 万 + 登报道歉 |

**钱流与责任流的方向**：钱从侵权人（家庭）流向企业（220 万），另一笔约 2080 万的钱从未离开企业（自己承担）。责任则从行为人（未成年人，限制能力）上移到监护人（父母）。**权力在这一链上是分散的：企业有"定赔付标准"的权力，法院有"定可赔范围"的权力，两者边界正是本案的争点。**

### 4.4 交付物二：度量视角

本案被三个数字衡量：**13 万、200 万、7 万**。加起来 220 万。

- **13 万怎么来的**：餐具损耗 + 清洗消毒。有采购单、有服务报价，可核。这是最硬的一段。
- **200 万怎么来的**：经营损失 + 商誉损失。判决未披露测算过程，但从量级看，走的是"客流量/营业额同期对比 + 影响时段"的路子。它依赖企业举证，因此**举证的完整度直接决定这一段的数额**。
- **7 万怎么来的**：律师费、取证费中"合理必要"的部分。注意，法院明确没有把"退一赔十"计入——这是全案最关键的一次口径切割。
- **谁定义**：13 万与 7 万由凭证定义，200 万由"可观测的经营数据"定义，而"什么算可赔"这条边界由法院定义。**真正的定义权在第三步：把哪一段划进"必要成本"。**

会不会被生产出来？会，而且生产空间恰好在这一步。企业有动机把"自主加码的支出"包装成"商誉损失"，因为两者在会计上都表现为费用，很难从账面上区分。这就是为什么陪审员要专门指出"十倍补偿属自主商业决策"——**这句话的作用，是把一段本来可以被计入损失的支出，从索赔基数里剔出去。**

**这是本案真正的技术含量**：不是算出了 220 万，而是把 2300 万拆开，指出其中约 2080 万不属于"侵权造成的必要后果"。

### 4.5 交付物三：真实权衡

**一对不能两全的约束：**

- 约束 A：**充分救济**。企业确实因侵权行为遭受了真实损失（客流下降、商誉贬损、补救支出），如果不充分赔偿，侵权成本过低，无法形成威慑；对未成年人侵权尤其如此——本案的判决要传递"未满 18 岁不是护身符"。
- 约束 B：**不替企业的自主决策买单**。如果全额支持 2300 万，等于司法承认"企业定多高的赔付标准，侵权人就得承担多高"，这会打开一个口子：任何企业都可以在危机中提高赔付标准，再把账单转给侵权人。

**为什么不能两全**：A 要求"损失全赔"，B 要求"只赔必要"。而"必要"与"自主"的分界线，恰好落在企业最有裁量权的那一段——补救支出。同一笔钱，企业说是"不得不花"，法院说是"可以选择少花"。**这条线的位置，决定了赔偿总额，也决定了谁承担企业的公关成本。**

**本案的选择**：把线画在"退款"与"十倍补偿"之间。退款算必要（修复商誉的最低动作），十倍补偿算自主（超出必要范围的加码）。**结果是：企业可以继续做"退一赔十"，但这份善意的成本留在自己账上。**

**这个选择的代价归属**：220 万落在两个家庭，约 2080 万落在企业股东。而侵权人的赔偿能力是有限的——两个 17 岁孩子的家庭，220 万已经是极重的负担。这意味着 A 约束（威慑）实际上被"赔付能力"限制了，真正起作用的是 B 约束（边界）。**判决在这里做了一个现实的选择：与其判一个执行不了的天价，不如判一个能执行、并且把边界讲清楚的数。**

### 4.6 交付物四：反方案 + 副作用

**替代方案：建立"商誉损失可赔上限公式"，把口径写进裁判指引。**

公式：`可赔商誉损失 = 受影响门店同期营业额跌幅 × 影响天数 + 必要补救支出（换具/消毒/退款）`；超出部分由企业自担，并在年报或公告中披露为"自主商业决策支出"。

**它解决了什么**：把"必要"与"自主"的分界线从个案裁量变成可预期规则。企业知道哪些支出能索赔、哪些不能，法院减少逐案解释成本，侵权人也能预判风险敞口。

**它新制造了什么**：

1. **跌幅取证依赖企业自己提供经营数据**。企业有动机把"影响天数"做大、把"同期基数"做高。**公式越精确，造数动机越强**——这是所有以企业自报数据为基础的规则的共同弱点。
2. **不同行业基线不同，统一公式会误伤小微**。一家单店的小餐馆与连锁品牌，同样的营业额跌幅意味着完全不同的生存压力；统一乘数会让前者赔不够、后者赔太多。
3. **把商誉彻底财务化，可能弱化对名誉权的保护**。名誉侵权的救济不止是钱，还包括停止侵害、消除影响、赔礼道歉。若一切折算成"营业额×天数"，那些没有明显营业额变化、但人格评价受损的情形会被挤出救济范围。
4. **上限一旦公开，会变成侵权方的"预算"**。可预期的赔偿上限，对侵权人而言就是可承受的成本——这在故意侵权（如本案的寻求刺激）情境下，反而可能降低威慑。

**新代价落在谁头上**：落在**司法裁量空间**与**小微经营者的救济充分性**上。前者被公式压缩，遇到新类型案件时缺少弹性；后者在统一乘数下可能拿不到与实际损失相称的赔偿。**这与作者反复讲的那件事同构：任何把复杂现实压成一个公式的努力，都会在公式覆盖不到的地方产生新的不公平。**
