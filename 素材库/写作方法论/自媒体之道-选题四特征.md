# 自媒体之道 — 选题四特征

## 核心方法论

吴晨光《自媒体之道》提出**好选题的四大典型特征**，deai-topic 选题评分时可对照检验：

1. **有冲突**：话题天然存在对立/矛盾（利益冲突、认知冲突、新旧冲突）——冲突是流量的燃料
2. **有悬念**：读者产生"然后呢？为什么？"的好奇缺口——悬念驱动点击
3. **有利益**：与读者的钱袋子/工作/生活直接相关——利益驱动关注（"这跟我有什么关系"）
4. **有情绪**：能引发共鸣/愤怒/焦虑/希望——情绪驱动转发

## 可复用公式/模板

```
选题四特征检验表：
□ 冲突：谁能从中获得什么/失去什么？（利益相关方分析）
□ 悬念：读者看完标题后的第一反应是"然后呢？"吗？
□ 利益：读者 30 秒内能说出"这跟我有什么关系"吗？
□ 情绪：评论区会出现"太真实了""气死了""终于有人说了"吗？

通过 ≥3 项 → 强选题；通过 2 项 → 合格选题；<2 项 → 考虑放弃或换角度
```

## 适用环节

- `deai-topic` Step 3 评分：在爆款潜力维度评估时，用四特征对照检验（与五要素评估互补）
- `deai-topic` Step 1.5 评论区挖掘：评论区的高赞内容往往命中"利益/情绪"特征——用户用点赞投票
- 选题卡「差异化策略」章节：四特征缺失项 = 差异化切入点（别人只有 2 项，你补齐 4 项）
