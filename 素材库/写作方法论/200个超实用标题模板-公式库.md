# 200 个超实用标题模板 — 公式库

## 核心方法论

200 个经过验证的标题句式，覆盖数字式/疑问式/悬念式/对比式/身份式/利益式等主流套路。
核心洞察：**句式是骨架，信息是血肉**——模板变量必须替换为本文真实内容，禁止照搬示例。

> 与《全平台爆款标题模版-公式库》的关系：本卡片句式更全（200 个 vs 66 个），
> 且含**已命名的中文示例**（迁移性强）。deai-title 候选池不足 12 个时优先用本卡片补充。

## 可复用公式/模板（已验证句式精选）

### A. 数字式（制造确凿感）

```
- "{数字}个为{对象}节省{金钱/时间}的技巧"
- "{数字}个{主体}危险信号"（"7 个存储涨价危险信号"）
- "{数字}个你应该知道的{话题}事实"
- "{数字}步像专家一样{做某事}"（"10 步像专家一样做 AI 选型"）
- "{数字}个{对象}最傻的{做法}，全都成功了"（反差式数字）
- "{数字}个{方法}，{效果}实测"（"3 个方法，存钱效果实测"）
- "为什么{人群}都{不做某事}？{数字}个原因"
- "{数字}个{主题}谎言以及如何识别它们"
- "{数字}个{主题}专家不想你知道的秘密"
- "关于{主题}的真相：{数字}个事实"
```

### B. 疑问式（引发好奇）

```
- "{对象}的隐藏秘密你知道吗？"
- "不同{人群}怎么选{品类}？"
- "{行为}真的有用吗？"（反常识质疑）
- "{对象}值那么多钱吗？"
- "你的{事物}并没有告诉你{秘密}"
- "{对象}可以成为{角色}吗？"
- "什么时候比较适合{方案A}或者{方案B}？"
- "为什么{大众认知}？这就是原因！"
- "如何克服对{事物}的恐惧？"
- "{对象}是一个濒临灭绝的品种吗？"
- "你是{某种特质}的 7 种迹象，中了几条？"
```

### C. 悬念式（话说一半）

```
- "你的{事物}并没有告诉你{秘密}"
- "揭示：为什么{现象}？"
- "{对象}不想你知道的{数字}个秘密"
- "关于{主题}的真相：{核心事实}"
- "很少有人知道的{方法}"
- "我们告诉自己的 {数字} 个谎言"
- "{数字}件没告诉{对象}的事"
- "提防{风险}以及如何识别它们"
- "{对象}的{真相}和{假象}"
- "这{数字}件事，知道的人少之又少"
```

### D. 对比式（制造张力）

```
- "{对象A}比{对象B}要好的{数字}个理由"
- "{月薪3000的A}与{月薪30000的B}的区别在哪里？"
- "同为{身份}，为什么差别这么大？"
- "一边{做A}，一边{做B}（对比冲突）"（"谁不是一边坚持，一边被迫"）
- "{身份A} vs {身份B}：谁才是真正的{主题}？"
- "世界上最便宜/最好/最贵的 {数字} 个{事物}"
- "{数字}个最有趣的{主题}故事"
```

### E. 身份式（锁定人群）

```
- "{人群}做对这件事，{好结果}"（"情侣做这十件事不会分手"）
- "{身份标签}：{典型行为/观点}"（"做了 5 年 B 端的人，都不太会面试"）
- "致所有{人群}：{忠告/建议}"
- "{人群}必看的{数字}个{避坑指南}"
- "他/她是{身份}，经历了{事件}，结果{反转}"
- "{低起点人群}，如何{高结果}？"（"月薪 7 千的小夫妻，如何存下 600 万？"）
```

### F. 利益式（明确收益）

```
- "学会{技能}，{收益}"（"学会这个技巧，月省 XX 元"）
- "{动作}前先看这份{指南}，{避坑承诺}"
- "如何{达到目标}？{数字}个{方法}让你{效果}"
- "{价格}以内能买到的{好东西}"
- "现在你可以花费较少的努力获得更多更好的{结果}"
- "在{时间限制}内{达到结果}的{方法}"
- "仅需{时间}/{数字}个技巧，让你轻松{学会某事}"
```

### G. 权威背书式（借势信任）

```
- "{权威来源}最吓人的 {数字} 句话，真不是常人所能读懂的"
- "研究了{名人/大厂}{数字}条{内容}，我发现他反复在说一件事"
- "{权威机构}提醒：{警示内容}，千万别不当回事！"
- "{行业老兵}{数字}年经验总结的{数字}个{技巧}"
- "从{名人/事件}看{普通人该懂的道理}"
```

### H. 认知颠覆式（反常识）

```
- "万万没想到，{反常识结论}！"
- "原来{这才是正确的做法}"
- "别让{坏习惯}毁掉你！"
- "还在{旧做法}？{新认知}才是{正确方向}"
- "你以为的{认知}，其实{真相}"
- "{旧事物}正在被{新趋势}淘汰"
```

## 使用规则

1. **句式替换**：模板变量必须替换为本文真实内容（数字/主体/结论），禁止照搬原示例
2. **平台适配**：小红书/头条偏"利益式+疑问式"（搜索导向）；公众号偏"故事式+悬念式"；知乎偏"疑问式"（提问匹配）
3. **结合 deai-title 六维评分**：公式库产出的标题同样进入候选池评分，不豁免
4. **融合升级**：单一句式基础上，尝试"数字 + 痛点 + 悬念 + 价值"融合（见 deai-title 类型十融合型）

## 适用环节

- `deai-title` 候选池不足 12 个时：优先用本卡片句式补充
- `deai-adapt-xiaohongshu` Step 2 标题改写：小红书标题直接套用"利益式+疑问式"公式
