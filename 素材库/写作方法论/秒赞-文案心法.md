# 秒赞 — 文案心法

## 核心方法论

林桂枝《秒赞》核心观点：**文案的功力在"秒"字——读者只用 3 秒决定是否被你的文字击中**。文案不是"写得好"，是"说得对、说得动人"。

三大心法：
1. **说人话**：像对人说话一样写文案——"写文案不是写作文"
2. **有画面**：用具体意象代替抽象形容（"热气腾腾" > "美味可口"）
3. **留余味**：话不说满，让读者自己补完——"说七分，留三分"

## 可复用公式/模板

```
去 AI 味对照（林桂枝视角）：
- 抽象词 → 具体意象："提升效率" → "省出 2 小时"
- 形容词堆砌 → 单一精准："高大上的奢华体验" → "坐进去就不想出来"
- 书面腔 → 对话感："值得注意的是" → "你注意过没"

文案三秒测试：
第一秒：读者看懂在说什么吗？（信息清晰）
第二秒：读者觉得跟自己有关吗？（利益相关）
第三秒：读者想继续看/想转发吗？（情绪/悬念）
```
