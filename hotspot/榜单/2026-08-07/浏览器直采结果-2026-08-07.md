# 浏览器直采结果 · 2026-08-07

## 一、browser-act 可用性诊断结论（用户已配合全部操作）

| 检查项 | 结果 |
| --- | --- |
| 安装 | ✅ browser-act 1.2.2（uv 安装，daemon 可重启） |
| 权限 | ✅ 用户已开启 WorkBuddy「Allow Full Access」 |
| daemon | ✅ 可重启，endpoint 正常（127.0.0.1:53053） |
| 阻塞根因 | ❌ **环境级删除保护**：WorkBuddy 对 `AppData\Roaming\browseract\` 下删除/重命名/替换操作强制走回收站，而本环境回收站不可用（`windows-sandbox-recycle-bin-unavailable`） |
| 连锁后果 | ① `main.log` 被保护组件以只读共享锁定 → CLI 无法写日志 → 任何 daemon 分派命令失败（`PermissionError`/`230331`）；② 同样拦截了 npm 安装（临时文件清理 EPERM）、PowerShell Remove-Item、Python os.remove（`-S` 绕过钩子后仍 WinError 5）、curl 落盘（临时文件+rename 被拦，size=0） |
| Edge headless | ❌ `--dump-dom` 退出码 21、零输出（同样被环境限制） |

**结论**：browser-act 无法在当前 WorkBuddy 环境运行，根因是环境对 AppData 路径的删除保护与工具日志滚动机制的不可调和冲突，与用户权限设置无关。
