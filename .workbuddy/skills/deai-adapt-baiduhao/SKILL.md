# deai-adapt-baiduhao — 百家号改写

## 平台特性

百家号是百度搜索生态的内容入口——读者通过百度搜索找到你的文章。这意味着百家号的内容寿命是所有平台中最长的（一篇优化好的文章可以持续获取搜索流量 1-3 年），但也意味着它必须满足百度搜索的排序规则。

| 维度 | 百家号 | 头条（对比） | 知乎（对比） | 改写影响 |
| :---: | :---: | :---: | :---: | --- |
| 流量来源 | 百度搜索（SEO 长尾） | 算法推荐 | 搜索+推荐 | 标题必须含搜索关键词，正文结构要利于爬虫 |
| 内容寿命 | 极长（1-3 年 SEO 长尾） | 24-48h | 72h+ | 值得投入时间做 SEO 优化，不做时效性标题 |
| 读者预期 | 找答案——带着问题来 | 消遣——刷到什么看什么 | 学习——想深入了解 | 开头直接给答案，不要铺垫 |
| 语气风格 | 中立客观 | 口语化、快节奏 | 理性专业 | 减少"我"，增加"数据显示""据统计" |
| 互动偏好 | 阅读量 > 收藏 > 评论 | 关注>收藏>评论 | 赞同>评论>收藏 | 目标是让读者读完，不追求评论区活跃 |

### 百家号内容在百度搜索中的排名逻辑

百度搜索排序的三个关键因素：

1. **标题含搜索词**：用户搜索的关键词在标题中出现，是排序的基础条件。标题越精准匹配搜索词，排名越靠前
2. **内容原创度**：百度判定原创内容（通过发布时间、相似度对比）给予更高权重。改写母稿时不能直接复制，要有实质性改动
3. **正文结构化**：百度爬虫对结构清晰的页面更友好。小标题（H2/H3）、列表、段落分明的内容更容易被索引

---

## 改写三原则

1. **标题是搜索入口，不是广告牌**：百家号文章的流量来自百度搜索，标题必须包含用户会搜索的词。母稿的悬念式标题在百家号不适用
2. **第一段直接给答案**：读者从百度搜到文章，是带着问题来的。第一段直接回答"这篇文章能解决什么"，不要让读者翻到第三段才找到答案
3. **少说"我觉得"，多说"数据显示"**：百家号读者不信个人观点，信数据、信事实、信权威来源。母稿中的主观判断改为客观引用

## 改写流程

### Step 0：确定文章标题（用于查找输入文件和命名输出文件）

在读取母稿之前，先确定文章标题：

1. **优先从标题方案提取**：
   - 检查 `drafts/{日期}/{选题名}/标题方案.md` 是否存在
   - 如果存在，解析评分表的各平台适配备注列，按优先级选取标题：
     1. **首选**：备注中标注"百家号首选"或"百家号"的标题（百家号偏好关键词前置式/数据驱动式标题）
     2. **次选**：无平台专属标注时，取排名第 1 的标题候选
2. **回退方案**：如果标题方案不存在或解析失败，使用 `{选题名}` 作为标题
3. **文件名安全处理**（`{标题}`）：
   - 替换 Windows 非法字符：`\ / : * ? " < > |` 为 `-`
   - 替换全角问号 `？`、全角冒号 `：` 为 `-`
   - 替换全角引号 `""`、空格为 `-`
   - 连续多个 `-` 合并为单个，去除首尾 `-`
   - 截断至 50 个字符
4. 将安全处理后的标题存入变量 `{标题}`，后续所有文件名均使用此变量

### Step 1：读取母稿

从 `drafts/{日期}/{选题名}/终稿-{标题}.md` 读取母稿。可选读取研究报告.md（补充数据引用和信源）。

### Step 2：百家号专用四问

1. **用户会搜什么关键词找到这篇文章？** 列出 3-5 个可能的搜索词组合，标题必须命中其中至少 2 个
2. **读者搜到文章后第一眼看到什么？** 前 100 字是否直接回答了搜索意图？如果不是，重写开头
3. **这篇文章哪些主观判断可以替换为数据？** "我觉得""我认为"都应该改为"数据显示""据XX机构统计"
4. **这篇文章的信息密度够吗？** 每段是否有实质信息？还是可以用 1 句话说完？

### Step 3：标题策略（百家号/SEO 专用）

百家号标题的**核心目标是搜索匹配**，不是制造好奇。母稿的标题策略在此完全不适用，需要重新设计。

| 类型 | 公式 | 母稿标题改造示例 |
| :---: | :--- | :--- |
| 关键词前置式 | 核心搜索词+价值承诺 | "Kimi K3 开源模型分析：2.8万亿参数免费开源对AI行业意味着什么" |
| 问答式 | 用户问题+答案摘要 | "OpenAI为什么批评Kimi K3开源？减速主义争议深度解读" |
| 数据驱动式 | 数字+主体+结论 | "6倍差价！Kimi K3与GPT-5.6定价对比，开源模型正在改写AI商业规则" |

**标题优化规则**：
- 前 15 字必须含核心搜索词——"Kimi K3""开源模型""OpenAI"等
- 标题不超过 28 字——百度搜索结果标题通常显示 28-30 字
- 不使用"震惊""出大事了"等标题党——百度算法会降权
- 不在标题中使用第一人称——"我"在百家号标题中降低专业感
- 标题承诺的答案必须在正文第一段开始兑现

### Step 4：正文改写——资讯化重构

#### 素材映射矩阵

| 母稿段落 | 百家号改写方向 | 具体操作 |
| :---: | --- | --- |
| 段1 钩子 | 去掉故事化开头，改为"结论先行" | "OpenAI 战略负责人 Dean Ball 公开批评 Kimi K3 开源是减速主义，其核心担忧是开源模型会削弱闭源 AI 的商业回报。但数据表明……" |
| 段2 背景 | 保留数据，去掉过渡句 | "Kimi K3 由月之暗面于 2026 年 7 月 16 日发布，参数规模 2.8 万亿，是目前全球最大的开源模型。在 Frontend Code Arena 中以 1679 分排名第一。" |
| 段3 定价权 | 保留价格表，增加数据解读 | 价格表 + "6 倍差价意味着企业在同等能力下，成本可降低约 83%。" |
| 段4 历史律 | 保留案例，去掉个人经历 | "2010 年代 AWS 做闭源云服务、OpenStack 搞开源，最终 AWS 降价应对。类似地，Android 开源与 iOS 闭源最终双轨并存。" |
| 段5 争议 | 保留观点冲突，去掉个人判断 | 只呈现双方立场，不加"我认为" |
| 段6 展望 | 保留趋势判断，去掉互动引导 | "综合来看，开源与闭源将长期并存。开源做广度，闭源做深度是正在形成的行业格局。" |

#### 六大改写操作

| 操作 | 说明 | 母稿原文 | 百家号改写后 |
| --- | --- | --- | --- |
| 结论先行 | 第一句给答案 | "Kimi K3 发布 3 天，用户请求把服务器打穿了" | "Kimi K3 发布后迅速成为 AI 行业焦点。本文从定价、历史和行业趋势三个维度分析此次开源争议。" |
| 数据强化 | 增加数据来源和出处 | "6 倍差价" | "6 倍差价。Kimi K3 输入价格 20 元/百万 Token，GPT-5.6 Sol 为 120 元/百万 Token（数据来源：月之暗面官网及 OpenAI 官网 2026 年 7 月定价表）。" |
| 人称替换 | "我"改为"本文""业内" | "我直说了吧" | "从商业逻辑看" |
| 去情绪化 | 情绪词改为事实陈述 | "有意思的现象" | "数据显示" |
| 加关键词密度 | 自然嵌入搜索关键词 | "Kimi K3 开源" | "开源大模型 Kimi K3 的开源策略对 AI 行业格局产生了直接影响" |
| 结尾收束 | 去掉互动引导，改为总结 | "评论区等你" | "以上是对 Kimi K3 开源争议的客观梳理。关注我，获取更多 AI 行业深度分析。" |

### Step 5：去 AI 化的百家号特化处理

| 百家号特有 AI 味信号 | 修复方式 |
| --- | --- |
| 开头有"我" | 改为"本文""业内分析""数据显示" |
| 主观判断无数据支撑 | 找到研究报告中的对应数据替换，或删除该判断 |
| 情绪化表达 | "我直说了吧""说实话"等全部删除 |

### Step 6：SEO 结构化要点

| 要素 | 操作 |
| :---: | --- |
| 关键词布局 | 标题含 1-2 个核心词。前 100 字自然出现 1 次。小标题含相关词 |
| 小标题（H2） | 每 400-500 字一个，用小标题分割段落，帮助爬虫理解文章结构 |
| 段落长度 | 每段 3-5 句，不超过 6 句。段落太长会降低搜索排名 |
| 原创度 | 母稿改写时，不能直接复制粘贴。每句话都要重新组织 |
| 内链 | 如有过往百家号文章相关内容，在正文中自然插入链接 |

### Step 6.5：封面图 AI 提示词与内容简介（发布必填项）

百家号发布时**封面图是必填项**（系统强制），且封面图会出现在百度搜索结果列表和推荐流中，直接影响点击率。内容简介对应百家号"摘要"字段，会展示在搜索结果中。

#### 封面图 AI 提示词生成规则

根据改写后文章的核心冲突、情绪基调和视觉风格，生成一段英文 AI 绘图提示词：

| 文章情绪基调 | 对应视觉风格 | 推荐配色 |
|:----------:|-------------|----------|
| 😡 愤怒 / 😰 焦虑 | 冲突对比、撕裂感、冷硬工业风 | 蓝橙对比、暗红+黑 |
| 🤔 好奇 / 🧠 优越感 | 科技感、数据流、发光粒子、未来主义 | 深蓝+青、紫金 |
| 👍 共鸣 / 😄 希望 | 温暖、人文叙事、柔和光影 | 暖黄+白、琥珀色 |
| 混合情绪 | 取主导情绪对应的视觉风格 | 主导色调+点缀色 |

**提示词结构**（三段式，用句号分隔）：

```text
{主体场景描述}。{环境/氛围/材质细节}。{画面约束（比例/风格/灯光）}。
```

**生成规则**：
- 首段：画面主体——文章最核心的冲突或场景（如"暴跌的K线图与上涨的内存芯片"）
- 中段：画面氛围——对应情绪基调的配色和材质（如"暗蓝背景、橙色数据流"）
- 尾段：画面约束——**百家号封面图统一使用 3:2 横版比例**（百度搜索结果列表展示横版封面），风格指定和灯光
- 语言：**统一用英文**（Midjourney/DALL-E 对英文支持最好）
- 不加文字：提示词中避免让 AI 生成文字（中文 AI 绘图很难写出正确汉字）
- 不加人物面部：避免 AI 生成恐怖谷效应的人脸

**输出格式**：在输出文件中用代码块包裹，标注 `[封面图提示词]`。

#### 内容简介生成规则

从改写后文章的结论段和核心数据中提取，用于百家号「摘要」字段。**与公众号的"悬念式"简介不同，百家号摘要是"答案式"的**——百度搜索用户带着问题来，摘要直接给出答案锚点，有助于提高搜索点击率。

- **字数**：≤ 100 字（中文）
- **内容**：核心结论 + 关键数据，不展开细节
- **语气**：中立客观，与正文语气一致
- **公式**：`{核心结论/关键数据} + {延伸信息提示}`

**输出格式**：在输出文件中用普通段落标注 `[内容简介]`。

### Step 6.6：文中配图规划

百家号正文中插入配图可提升完读率和搜索页停留时长；同时**配图是百度图片搜索的流量入口**，每张图都有独立的 SEO 价值。配图不能为了插而插，每张图必须有明确的叙事功能。

#### 配图类型与适用场景

| 配图类型 | 功能 | 适用位置 | 视觉风格 |
|:--------:|------|----------|----------|
| **数据可视化** | 把关键数字变成可感知的画面 | 核心数据引出后 | 图表化、信息图风格 |
| **概念隐喻** | 用视觉比喻解释复杂概念 | 难度较高或抽象段落之后 | 极简3D、概念渲染 |
| **情绪放大** | 放大读者当前的阅读情绪 | 情绪转折点、金句前后 | 氛围化、光影为主 |
| **节奏换气** | 长段落之间做视觉间隔 | 连续分析段落的中间 | 留白多、极简构图 |
| **场景对比** | 过去vs现在/正vs反的视觉对立 | 对比论证段 | 左右分屏、冲突色调 |

#### 配图数量规则

- 1500字以下 → 0-1张（封面足够了）
- 1500-2500字 → 1-2张（含封面）
- 2500-3500字 → 2-3张（含封面）
- 3500字以上 → 3-4张（含封面）
- **原则**：宁少勿多。一张没有信息量的图不如不放

#### 配图插入位置判断

改写完成后，通读全文，在以下位置判断是否需要配图：

| 信号 | 建议动作 |
|------|----------|
| 连续出现 2 个以上关键数据 | 插入一张数据可视化配图，把数据量变成视觉量 |
| 有一个需要读者"想象"的抽象概念 | 插入一张概念隐喻配图，让抽象落地 |
| 金句/转折句之后 | 插入一张情绪放大配图，放大读者此刻的感受 |
| 连续 3 段以上纯文字分析 | 插入一张节奏换气配图，给读者视觉休息 |
| 对比论证（A vs B / 过去 vs 现在） | 插入一张场景对比配图，强化对立感 |

#### 配图 AI 提示词生成规则

每张配图独立生成一段 AI 绘图提示词。

**提示词结构**（三段式，用句号分隔）：

```text
{主体场景描述}。{环境/氛围/材质细节}。{画面约束（比例/风格/灯光）}。
```

**生成规则**：
- 首段：画面主体——该段文字中你最想让读者"看到"的核心意象
- 中段：画面氛围——对应改写后文章的情绪基调
- 尾段：画面约束——**正文配图统一使用 16:9 横版比例**（百家号正文图片以横版展示效果最佳），风格指定和灯光
- 语言：统一用英文
- 不加文字，不加人物面部
- 同一篇文章内各配图的视觉风格保持一致（色调/材质/渲染方式统一）

#### alt 文本（百家号特有——图片 SEO 必填）

百家号发布时每张配图可填写 **alt 文本**（图片描述），百度图片搜索依赖 alt 进行索引。**每张配图必须生成一条中文 alt 文本**：

- 字数：≤ 30 字（中文）
- 内容：图片画面的核心内容 + 相关关键词（如"SK海力士股价暴跌K线图"）
- 作用：①百度图片搜索流量入口 ②无障碍阅读 ③图文相关性信号

#### 定位方式与配图位置规范

每张配图通过**锚文本**指明插入位置——锚文本取所在段落的**第一句**（整句或前 5-15 字），配图插入到该段之后（结束位置）。所有配图均插入在段落后，不出现在段落中间。

**锚文本选择规则**：
- 锚文本取自所在段落的**第一句**——第一句在段落开头，搜索时最先命中，定位最快
- 长度 5-15 字：第一句不足 5 字则整句作锚文本；超过 15 字则截取前 15 字，必要时附段落序号
- 必须是正文中唯一的——如果同一个短语出现多次，附加"第 N 次出现"或加上下文
- 优先选包含数字/引号/关键词的第一句——这些在视觉上容易定位
- 不使用"我""你""它"等通用代词作为锚文本
- 锚文本必须精确到该段内——如果段落较长，可附段落序号辅助定位

**配图位置规范（百家号专有）**：
- ✅ 正确：配图插入在段落**之后**（段后空行→配图→空行→下一段）
- ❌ 禁止：配图出现在段落**中间**（一段文字被图片切断）
- ❌ 禁止：配图插入在句子中间（一句话没说完就被图片打断）
- 例外：封面图不受此限制（封面图属于文章头部元数据，不涉及段落内位置）

**输出格式**：

```markdown
[配图1] 插入位置：在锚文本"XXX"之后的段落后。{画面描述 + prompt}。alt：{中文alt文本}
```

#### 搜索替换指令

输出文件末尾附带，帮助写作者快速定位：

```markdown
## 配图搜索替换指令

按以下顺序操作：
1. 在正文中搜索锚文本"{锚文本1}" → 在其 {"之后"或"之前"} 插入 {配图1}，并填写 alt 文本
2. 在正文中搜索锚文本"{锚文本2}" → 在其 {"之后"或"之前"} 插入 {配图2}，并填写 alt 文本
...
```

## 质量自检

| 序号 | 检查项 | 标准 |
| :---: | :--- | :--- |
| 1 | 标题含搜索关键词 | 前 15 字含至少 2 个搜索词 |
| 2 | 第一段给答案 | 前 100 字直接回应标题承诺 |
| 3 | "我"出现次数 | 全文不超过 2 次 |
| 4 | 数据支撑比例 | 关键论点有数据来源，非个人感受 |
| 5 | 小标题（H2）个数 | ≥3 个 |
| 6 | 段落长度 | 无连续 >6 句的段落 |
| 7 | 结尾收束 | 以总结性陈述收尾，非开放性问题 |
| 8 | 原创度 | 与母稿的表述差异 ≥ 50%（非直接复制） |
| 9 | 封面图提示词 | 存在且为 3:2 横版比例，含三段式结构（主体/氛围/约束） |
| 10 | 内容简介 | ≤100 字，为"答案式"摘要（含核心结论+关键数据），非悬念式 |
| 11 | 配图信息完整 | 末尾配图详情中每个"插入位置"都有明确的锚文本，且锚文本在正文中能找到唯一的匹配位置；每张配图都有 alt 文本 |
| 12 | 正文无标记残留 | 正文中不包含 `[配图` 字符串——确认没有遗留任何配图标记 |

## Input

- `drafts/{日期}/{选题名}/终稿-{标题}.md`（必需——母稿。`{标题}` 来自标题方案排名第 1 的候选标题，无标题方案则使用选题名）
- `research/{选题名}/研究报告.md`（可选——用于补充数据引用和信源）

- `drafts/{日期}/{选题名}/百家号-{标题}.md`（百家号适配版）
