# `deai-author-voice` — 作者观点蒸馏（挖三观）

## When to Use
- 每日流水线末尾（deai-daily-pipeline Step 11.5 调用）：向作者提问，收集当天产出反馈 + 挖掘新观点
- 作者观点库（notebook/）需要扩充时：批量向作者深挖某主题的立场
- 写某篇深度文前缺作者观点：现场蒸馏立场，再落笔

## Input
- `notebook/` 现有作者观点库（先读 README.md 与已有笔记，避免重复提问、发现待补空白）
- 当日选题 / 目标主题（决定提问方向）
- 待挖掘的主题域（如：消费/平台/阶级/科技/劳动/财富），可多轮覆盖

## Output
- 蒸馏结果 → 沉淀回 `notebook/`（新笔记 / 修订既有笔记，frontmatter: date/tags/type）
- 「作者观点图谱」汇总（核心观点 / 价值观维度 / 表达武器库），供 deai-research 消费

---

## 核心方法论：挖观点 ≠ 问观点

**调研结论（2026-08-22 Deep Research）**：你直接问"你的观点是什么"，得到的往往是人云亦云的套话。真正的观点藏在**层层追问**里。本技能基于以下经过验证的方法体系：

### 方法一：苏格拉底式五类提问（追问架构）
不满足于第一层回答，用五类问题逐层下钻：

| 类型 | 句式 | 作用 | 示例 |
|------|------|------|------|
| ① 澄清 | "你说的 X 具体指什么？能举个例子吗？" | 把模糊表态变成具体立场 | "你说的'资本跑路'，具体指哪种行为？" |
| ② 假设 | "你这个判断建立在什么假设上？如果假设不成立呢？" | 挖出隐藏前提 | "你默认资本家一定会转移资产，为什么？" |
| ③ 理由证据 | "支撑这个观点的经历/数据是什么？" | 追溯观点成因 | "是什么经历让你得出'退赔优先级不重要'？" |
| ④ 推论结果 | "按你的说法推下去，会有什么后果？" | 看观点边界 | "如果都靠制度约束资本家，谁会受益谁受损？" |
| ⑤ 对立视角 | "持相反观点的人会怎么反驳你？在什么情况下你的观点不成立？" | 检验观点韧性 | "有人会说这是道德问题不是制度问题，你怎么看？" |

**用法**：对作者的第一层回答，至少追问 1-2 个"下钻问题"，直到得到**具体、有立场、可写作**的判断。

### 方法二：Laddering 阶梯法（从偏好爬到价值观）
源自 Means-End 理论：从作者随口提的**具体偏好/经历**出发，连续问"这对你重要吗？为什么重要？这让你获得了什么？"（软阶梯式变化措辞），逐级爬升：

```
属性（作者说了什么）→ 后果（这带来了什么/避免了什么）→ 价值观（这满足了什么深层原则）
```

- 一条阶梯约 5-7 层，爬到头（对方答不出/重复）即到价值观层。
- 示例：作者说"我讨厌大平台收割" → "收割了什么？" → "把普通人的生存空间挤掉了" → "你其实是关心什么？" → "我关心普通人的选择权和生存权利" → **价值观：公平/弱者保护/反垄断**。
- **软阶梯变体**：不用机械的"为什么"，交替用"这让你想到什么""继续说""还有呢"保持对话感。
- 一次访谈产 3-5 条阶梯，跨阶梯反复出现的价值观 = 作者最核心的三观。

### 方法三：施瓦茨价值观分类（蒸馏结果归位）
把追问挖到的立场，归入施瓦茨 10 类基本价值观，识别作者的"价值轴"：

| 价值维 | 施瓦茨类型 | 识别信号 |
|--------|-----------|----------|
| **自我超越** | 世界主义/仁慈 | 关心弱者、公平、社会正义、环境 |
| **自我提高** | 权力/成就 | 竞争、赢、掌控、地位、效率 |
| **保守** | 安全/遵从/传统 | 秩序、稳定、规则、延续 |
| **开放** | 自我导向/刺激 | 独立、自由、创新、反叛、冒险 |

> 蒸馏目标：识别作者在"自我超越 vs 自我提高""保守 vs 开放"两个轴上的位置，以及反复出现的核心价值——这些才是支撑其所有观点的"三观底层"。

### 方法四：三观三层问答（直接结构）
针对"世界观/人生观/价值观"三层分别设计问题，快速建立作者三观全景：

| 层 | 问什么 | 示例 |
|----|--------|------|
| **世界观**（世界怎么运转） | 世界/社会的底层规律是什么？什么东西在驱动变化？ | "你觉得这个社会真正由什么驱动？金钱？权力？技术？" |
| **人生观**（人该怎么活） | 你想成为什么样的人？人活着最重要的是什么？ | "在你的标准里，一个人活得好是活成什么样？" |
| **价值观**（什么值得支持） | 你支持什么、反对什么、羡慕什么、厌恶什么？ | "你最厌恶的三种商业行为是什么？为什么？" |

### 方法五：SPiKY POV（观点锋芒挖掘）
内容创作者方法：挖"作者敢不敢站队"：

```
- 你相信什么，但大多数人不相信？     ← 最强观点金句源
- 什么让你愤怒/不爽？为什么？       ← 批判性观点的情绪源
- 你最不能妥协的一件事是什么？      ← 价值观底线
- 你近三年改变了哪个看法？当时为什么？ ← 观点演变轨迹
```

> **调研要点（2026-08-22 已验证）**：好提问的标准——①开放非封闭（不用"是不是"）②先易后难（先建立信任再下钻）③一次一问（不连珠炮）④追问有效期"选作者的原话、不植入自己的假设" ⑤沉默也是工具（留白让作者自己补）⑥宏观+微观结合（既问大局又问具体时刻）。

## Procedure

### Step 0：读取现状（避免重复提问）
- Read `notebook/README.md`（格式约定）+ 全部 `notebook/*.md` 笔记
- 产出「观点已有盘点」：哪些主题已有观点（不重复问）、哪些主题空白（重点挖）
- 若作者观点库已厚，当天提问聚焦"当日产出校准 + 空白主题补挖"，每次 ≤4 问

### Step 1：设计问题（遵循五法，每次 ≤4 个选择题）

**⚠️ 问题四段式结构规范（2026-08-22 用户反馈升级，强制）**：向作者提问时，**禁止裸问问题或只给标签式选项**。每个问题必须呈现为以下四段式，保证作者不看任何原文也能定位事件、听懂问题、看懂每个选项在说什么：

```
【① 背景 · 事件上下文】≤80 字，一句话讲清：谁/何时/什么事件/核心数字/今日文章立场——
   例：8/21 市场监管总局发布 9 家车企召回 427 万辆，起因是车内应急拉手颜色太贴近内饰；今日文章立场是"为新国标兜底叫好"。
【② 问题】有立场指向的提问（非"你怎么看"式空泛）——
   例：网上主流都在夸"车企主动负责"，你的真实判断更靠近哪一边？
【③ 为什么问】≤40 字，告诉作者：这个问题会挖到什么观点、答案将如何使用——
   例：校准你在"产品安全设计"观点域的站位，答案沉淀进 notebook 当后续文章立论。
【④ 选项】3-4 个【主句 + 括号解释】格式的完整立场选项——
   格式：`{立场主句}（{括号内说明：这个判断的依据/具体含义/与别的选项差在哪}）`——主句与括号解释在同一选项内自洽，作者不依赖任何折叠说明即可读懂
   ❌ 只有标签或主句："乐观""悲观""利空即利好"（作者无法判断你到底在说什么、选项间差什么）
   ✅ 主句+括号："利空即利好——技术够格才被拦（封堵发生在技术验证之后：会被拦说明已够格，方向不变，IPO 受理是资本认可）"
```

**⚠️ AskUserQuestion 呈现禁令（2026-08-24 用户复核补强，强制）**：用 AskUserQuestion（或任何选择题 UI）呈现选项时，**『主句+括号解释』必须作为单一选项文本整体写入选项 label**（作者直接可见），**禁止拆成 label=主句、description=解释 两栏**——多数 UI 只渲染 label，description 折叠/不可见，拆开 = 作者看到的仍是裸标签，等价违反 2026-08-22 规范。格式：label = `{立场主句}（{依据/含义/与相邻选项差异}）`；description 仅可放补充性辅助信息（如"此选项在 X 平台曾获高赞"），不得承载括号解释。历史教训：2026-08-23 曾把解释放 description 栏，作者复核发现"候选答案没有用括号加解释"。

**选项设计三准则**（2026-08-22 用户反馈两轮固化，做选项前逐条自检）：
1. **可判定**：每个选项 = 立场主句 +（括号解释），括号内讲清"为什么这么判断/意味着什么"，作者不依赖任何折叠说明即可读懂自己在同意什么
2. **可辨析**：选项之间是"立场分叉"而非"措辞微调"；括号解释强化差异点（例：主句"短期偏空"需配括号"苹果级别客户的单量，内循环替代不了"以区别于"利空即利好"）
3. **可写作用**：选项主句即入库观点句，选中后可无需二次加工直接进 notebook；括号解释可并入笔记作为理由支撑

**背景素材来源（强制）**：提问前必须先从当日融合榜单/选题卡/研究报告提取事件要点（时间、主体、关键数据、文章结论），填入【① 背景】；若话题复杂，背景可扩为两行"事件时间线"；若作者是亲历者，背景可只保留"今日文章说了什么"。

**问题组合模板**（每轮从以下 6 个槽位中选 ≤4 个，按需定制到当日主题；每槽给出"背景/问题/选项"写法示例）：
1. **观点校准槽**（针对当日三篇）：
   - 背景写："{选题名}：{核心事件一句话}；今日文章落脚 = {文章结论一句话}"
   - 问题写："网上主流都在说 {主流观点}，你最有把握说'他们都错了'的是哪句？你的真实判断是什么？"
   - 选项写：≥3 个「主句+括号解释」（主句=反主流判断，括号=理由/含义），如"利空即利好——技术够格才被拦（封堵发生在技术验证之后：会被拦说明已够格，方向不变，IPO 受理是资本认可）"
2. **下钻槽**（对某观点追问）：
   - 背景写："{你上一篇观点/作者刚表达的观点一句话}——记住你原话：'...'"
   - 问题写："你凭什么这么说？支撑这个判断的具体经历/数据是什么？"
   - 选项写：≥2 个「主句+括号解释」的"可能来历"立场句（主句=亲历案例/行业见闻/数据观察，括号=补充细节）+ 鼓励自由输入——按作者的原话下钻，不植入自己的假设
3. **对立槽**（观点韧性检验）：
   - 背景写："有人会这样反驳你：{反方观点一句话}（如：美光游说是合理的产业政治博弈）"
   - 问题写："这个聪明人的反驳，你会怎么回？会让步还是更强硬？"
   - 选项写：≥3 个「主句+括号解释」覆盖"部分让步/坚持+补理由/更强硬反击"梯度，括号内点明与相邻选项的差异
4. **价值观槽**（Laddering 顶层）：
   - 背景写："你反复写到 '{关键词}'（如公平/制度）——在你批评的 {某事件} 里反复出现"
   - 问题写："对你来说，'{关键词}'到底意味着什么？它重要是因为什么？"
   - 选项写：≥3 个「主句+括号解释」的"价值观定义句"（主句=定义，括号=含义+为什么重要），如"兜底性——让弱者不靠运气活着（规则最重要的是给没资源、没话语权的人兜底）"
5. **SPiKY 槽**（锋芒挖掘）：
   - 背景写："你做过 {领域}——在这行里有个大家习以为常的现象：{现象一句话}"
   - 问题写："这个现象里，最让你觉得荒谬、想骂人的是哪个细节？一句话说透。"
   - 选项写：≥3 个「主句+括号解释」的"可直接成金句"立场句（主句=金句，括号=现象细节佐证）+ 明确鼓励自由输入（这里是金句来源，自由输入优先级最高）
6. **世界观槽**（底层三观）：
   - 背景写："在你熟悉的那套产业运转规则里——{具体场景一句话}"
   - 问题写："那套规则里最虚伪/最真实的一环是什么？它被包装成什么样？"
   - 选项写：≥3 个「主句+括号解释」的完整判断句（主句=点破叙事包装，括号=包装成什么/谁受益）
7. **风格挖掘槽（2026-08-26 新增——不只挖观点，挖"作者咋说话"）**：
   - 目的：作者原话是**风格画像卡**的唯一权威来源——每次回访主动记录作者的自发表达（反问式收束、口语金句、毒舌命名、比喻习惯），完善 `notebook/作者风格画像.md`（作者风格数据；方法模板与六层结构定义见 `deai-write/references/作者风格画像卡.md`）
   - 背景写："{今日某文章里你最喜欢的自己的一句话}——你写文章时，是不是经常用这种口气？"
   - 问题写："除了内容，你希望自己的文章读起来是什么味儿？（毒舌/冷静算账/看热闹不嫌事大/拍案而起）——给我一句你平时说话的样子。"
   - 选项写：≥3 个「主句+括号解释」的**风格自陈句**（主句=作者自我风格定位，括号=典型句式举例，如"会算账的老江湖——爱用反问收Boss，'企业凭什么老老实实发薪'"）+ **明确鼓励自由输入**（自由输入 = 原声金句，优先级最高）
   - 落地：作者回答中的**原话句式/金句/毒舌命名**必须原样记入风格画像卡对应小节；若回答翻新了既有风格描述，更新画像卡

### Step 2：交互执行
- 用 AskUserQuestion 发起（≤4 问，每题 2-4 选项 + 允许自由输入）
- **每题呈现顺序（强制）**：① 背景（事件上下文）→ ② 问题 → ③ 为什么问 → ④ 选项。**背景必须放在问题之前**；选项统一为「主句 + 括号解释」格式，每个选项单独读即可自洽（作者直接读懂自己在同意什么，不依赖任何折叠/追加说明）
- **追问规则**：选项回答背后往往有更深观点——若作者选了某个选项，判断是否值得用追问下钻（下钻时同样先给背景再问）；对话式追问有限次数（回合太长会疲劳），以"回答能写成观点"为够
- **作者疑惑时**：若作者回复"不懂你在问什么/选项啥意思"，视为背景不足的信号——补一句事件时间线或文章原句再重问

**⚠️ 自由输入捕获（2026-08-26 确立——选项是"盖章"，自由输入是"签名"）**：
- **核心认识**：作者**只要不是单纯点选选项**——选了选项还追加文字、直接写一段话、用"其他"自由输入——这段文字**就是作者最自然的表达方式**，风格含量远超任何选项。**观点可以从选项拿，风格只能从自由输入拿。**
- **捕获触发（强制）**：每轮交互结束后，逐个检查作者回答——凡含**自由输入成分**（非纯选项文本）的回答，一律进入"原声样本"捕获队列，**不得丢弃**（哪怕该问题已经通过选项拿到观点）
- **捕获时机**：当场记录，不等到整轮结束——建议把自由输入原话先存到临时处（如当日草稿目录），Step 3.5 统一归档
- **捕获内容**：①原话全文（一字不改）②上下文（哪个问题哪个选题/作者在回应谁的什么说法）③初判风格特征（句式/论证/情绪/金句模式）——初判规则见 `notebook/作者原声样本库.md` 的 L1 层
- **对纯选项回答**：不产生风格样本（选项是 AI 拟的，代表 AI 的表达不是作者表达），仅取观点即可

### Step 3：蒸馏（把回答加工成观点底座）
把原始回答按以下结构加工（**必须引用作者原话**，不代作者发明立场）：

```
### 作者观点图谱（{日期} 蒸馏）
#### ① 核心观点（可写作立场）
- {一句话立场}（出处：作者原话"..."）
#### ② 价值观归位（施瓦茨分类）
- 主价值轴：{自我超越优先 / 自我提高优先 / ...}
- 高频价值：{公平 / 反垄断 / 弱者保护 / 掌控 ...}（来自 Laddering 跨阶梯反复项）
#### ③ 表达武器库（写作可直接调用）
- 观点金句：{"..."}
- 批判靶子：{作者反对的 X}
- 情绪与站队：{作者偏向哪方、反感哪方}
- spiky POV：{作者敢说的反共识判断}
#### ④ 文风层（2026-08-26 新增——放"作者怎么说话"，供风格画像卡回填）
- 原声句式：{作者回答中最具个人特色的原话 1-2 句，逐字保留}
- 语言指纹：{反问连击 / 口语长句 / 设问自答 / 点名俚语 / 判断句}
- 金句模式：{对仗 / 俚语化 / 判断式 / 反问式——命中的模式}
- 情绪姿态：{克制愤慨 / 毒舌反讽 / 怀疑留白 / 亲身在场}
- 回填动作：{→ 更新 notebook/作者风格画像.md 哪些小节}
```

### Step 3.5：原声归档到样本库（2026-08-26 确立——观点进 notebook，原声进样本库，两条线分开走）

**原则**：观点沉淀（Step 4 进 `notebook/`）与风格沉淀（本步进 `notebook/作者原声样本库.md`）是**两条独立流水线**——观点回答可能被改写，**原声一个字都不能改**。作者说话的样子，是后续文章"像不像作者"的唯一原料。

执行：
1. **盘点捕获队列**：收集 Step 2 捕获的全部自由输入回答（含纯自由输入 + 选项但追加文字的"追加部分"）
2. **逐条按 L2 模板归档**到 `notebook/作者原声样本库.md`「三、滚动样本区」顶部（模板见样本库文件头）：
   - 原话：逐字保留，不含 AI 改写；若回答夹杂选项文本，只归档追加的自发部分
   - 上下文：哪个选题/哪个槽位/作者在反驳谁的什么说法（帮未来蒸馏定位场景）
   - 风格初判：按画像卡六层打标签（句式=[...] 论证=[...] 情绪=[...] 金句=[...]）
   - 可引用金句候选：若有可直接进文章的原话，单独标出
3. **无自由输入时**：本步标"N/A（本轮全为选项作答）"——不虚构样本
4. **纯选项回答中作者追加的关键句**：若追加句子含立场（如"我补充一句：…"），该句子同时进样本库（风格）+ 观点沉淀（Step 4）

### Step 4：沉淀回 notebook（强制）

**沉淀命名制：主题制，非日期制**（2026-08-22 作者指正）——观点库按**观点域**组织，日期是 frontmatter 元数据不是文件名；同一主题持续追加到同一文件（详见 `notebook/README.md`）：

- **新建**：`notebook/{观点域短名}.md`（frontmatter: date/tags/type=opinion|rant）——仅当 notebook 中**没有**承载该观点域的文件时新建；短名 4-15 字点明观点域（如 `制度激励与资本转移.md`）
- **追加**：notebook 已有同观点域文件 → 在该文件内新增小节（`## {YYYY-MM-DD}：{新增观点}`）并更新 frontmatter 的 `updated` 字段，**禁止另起日期前缀新文件**
- **修订**：在相关既有笔记追加「作者修订·{日期}」小节
- **更新**：若当日有选题，把蒸馏结果写回对应选题目录的「作者观点底座」（供 deai-research 直接消费）
- 所有沉淀必须带 frontmatter（date/tags/type），供 deai-research 检索与溯源

### Step 5：闭环确认
- 验证新观点可被 deai-research 检索（该观点关键词能在 notebook 命中）
- 产出「本次蒸馏摘要」：挖到了什么新立场、哪个价值轴强化/新增、作者情绪倾向变化
- **文风回填确认（2026-08-26 新增）**：若本轮出现作者**原声句子/新金句/口语命名**，必须将原文回填进 `notebook/作者风格画像.md`（作者风格数据；方法模板与六层结构定义见 `deai-write/references/作者风格画像卡.md`）（句式层/金句清单/情绪层对应小节）——风格画像卡只从作者原话长，不从 AI 想象长
- **📊 周期蒸馏触发检查（2026-08-26 新增——积累的核心机制）**：检查 `notebook/作者原声样本库.md`「滚动样本区」新增条目数：
  - **触发条件**：新增 ≥10 条，或距上次蒸馏 ≥7 天（两者取先到）
  - **执行蒸馏**：通读样本库新增原话 → 统计重复出现的句式/词汇/论证/情绪/金句模式 → 新模式回填 `notebook/作者风格画像.md` 对应小节（如新增句式"什么时候…什么时候…"排比反问）→ **反向净化**（画像中找不到 ≥2 条样本支撑的描述 → 降级或删除，防 AI 自创风格）→ 在画像更新处标注"样本库 N 条蒸馏，{日期}"
  - **不满足触发**：跳过但不标注"无需蒸馏"——在蒸馏摘要里记"样本累计 {N} 条，距上次蒸馏 {d} 天"

## 质量门禁（蒸馏是否达标）

| 检查项 | 达标标准 |
|--------|----------|
| 提问有立场指向 | 每个问题都能逼出"支持/反对/判断"，不是开放闲聊 |
| **背景完整（2026-08-22 新增）** | 每个问题含【背景】段（事件/数据/文章立场一句话），作者无需看原文即可定位；选项为「主句 + 括号解释」格式（非裸标签），单独读即可懂 |
| 有下钻 | 至少 1 个问题用苏格拉底/Laddering 连续追问到价值层 |
| 观点可溯源 | 每条核心观点标注作者原话，不添加 AI 代拟立场 |
| 价值观归位 | 蒸馏结果落入施瓦茨分类或明确标注"作者新价值轴" |
| 沉淀完整 | notebook 新笔记/修订已写入，含 frontmatter+tags |
| **文风留存（2026-08-26 新增）** | 作者回答中的原声句子/新金句/口语命名已回填 `notebook/作者风格画像.md`（无新风格产出时可标 N/A，但必须说明） |
| **自由输入必归档（2026-08-26 新增）** | 本轮凡含自由输入成分的回答（非纯选项），已逐字归档进 `notebook/作者原声样本库.md`「滚动样本区」（含上下文+风格初判）；纯选项轮次标"N/A（全为选项作答）"；遗漏归档 = 风格积累断裂，视为未达标 |
| **周期蒸馏状态** | 触发条件满足时已执行蒸馏并回填画像卡；未触发时已记录"样本累计 N 条、距上次蒸馏 d 天" |
| 可复用 | 观点图谱可直接被 deai-research 消费（后续写作主脑） |
