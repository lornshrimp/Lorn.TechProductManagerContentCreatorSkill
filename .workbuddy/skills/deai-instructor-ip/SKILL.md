# `deai-instructor-ip` — 讲师个人品牌 IP 打造

## When to Use
- 需要从"写作者"升级为"讲师 IP"（有品牌、有产品、有变现）
- 需要规划个人品牌定位与内容策略
- 需要设计课程产品矩阵与变现路径
- 需要将自媒体流量转化为培训/咨询业务

## Input
- 用户输入：IP 方向/目标（如"企业培训师""AI 赋能专家"）
- 现状盘点：`my-articles/`（内容资产）、`resume.md`（专业背景）、`published/`（流量数据）
- 可选：`deai-knowledge` 素材库 → 《网红讲师 IP 打造方法论》卡片

## Output
- `ip/{IP名}/IP定位.md`（定位系统）
- `ip/{IP名}/内容与流量策略.md`（内容系统 + 流量系统）
- `ip/{IP名}/产品矩阵.md`（产品系统）
- `ip/{IP名}/变现与运营计划.md`（运营/粉丝/道场/变现系统）

---

## 核心理念

**讲师 IP 不是"网红讲师"，是"个人品牌商业体"**。核心公式：

```
个人品牌 IP = 专业能力 × 内容表达 × 商业设计
```

**IP 打造两句话**（来自《网红讲师 IP 打造方法论》）：
1. **内修品质搞内容**——扎实的专业知识 + 持续的内容输出（这是地基）
2. **外立品牌搞流量**——系统化的品牌定位 + 公域流量获取（这是杠杆）

**警告（方法论原话）**："红到发紫必被反噬"——IP 打造不是追求爆红，是**可持续的专业人设**。

## Procedure

### Step 1：定位系统（我是谁）

**定位 = 一句话说清"你是做什么的、帮谁解决什么问题"**：

```
定位公式：{人群} × {问题} × {专业方法} × {差异化}
示例：帮【中小企业主】解决【线上获客难】的【全域营销方法论】专家，区别于"只讲理论"的培训机构
```

| 定位要素 | 说明 | 自检问题 |
|----------|------|----------|
| **目标人群** | 你的学员/客户是谁 | 一句话能说清吗？ |
| **核心问题** | 你解决什么问题 | 这个问题够痛吗？ |
| **专业方法** | 你用什么方法/框架解决 | 有可命名的方法论吗？（如"全域八卦 IP"） |
| **差异化** | 为什么是你不是别人 | 有独家经验/视角/案例吗？ |

**人设基线联动**：IP 定位与 `persona-product-manager-shrimp.instructions.md` 一致——IP 是"产品经理独孤虾"的自然延伸（产品方法论 + 培训 + 咨询），不是另起炉灶。

### Step 2：内容系统（我持续产出什么）

**内容 = IP 的证明**。内容策略基于定位，形成"内容金字塔"：

| 层级 | 内容类型 | 目的 | 频率 | 来源 |
|:----:|----------|------|:----:|------|
| **塔尖** | 深度文章/课程（2500+ 字） | 建立专业权威 | 每周 2-3 篇 | `deai-daily-pipeline` 产出 |
| **塔身** | 短视频/直播切片 | 扩大触达 | 每周 3-5 条 | `deai-video-script` 产出 |
| **塔基** | 观点短评/问答互动 | 维持存在感 | 每日 1-2 条 | 评论区/想法/朋友圈 |

**内容三原则**：
1. **一致性**：所有内容围绕定位，不跑题（"关注我的都知道我讲什么"）
2. **可辨识**：有个人风格（口头禅/观点立场/表达方式）——去 AI 化的个人印记
3. **有增量**：每条内容给"第一次看到"的信息/视角

### Step 3：流量系统（公域→私域）

**公域引流**（内容获客）：
- 各平台内容分发（现有 5 平台 + 小红书/视频号）
- 平台选择与定位匹配（深度内容→知乎/公众号；种草式→小红书；快节奏→头条/视频号）
- **爆款是引流的放大器**：一篇爆款带来的关注 > 十篇普通文章

**公域→私域转化**（关键漏斗）：
```
公域内容（曝光） → 关注/收藏（浅层关系） → 私域（社群/个人号/公众号） → 转化（课程/咨询）
```

**私域承接**：
- 公众号（沉淀内容 + 信任）
- 社群/个人号（深度互动 + 需求挖掘）
- 朋友圈（人设展示 + 成交场景）

### Step 4：产品系统（我卖什么）

**IP 产品矩阵（分层设计，对应不同客单价）**：

| 层级 | 产品 | 客单价 | 目的 | 来源 |
|:----:|------|:-----:|------|------|
| **引流层** | 免费/低价内容、资料包、公开课 | 0-99 | 获客、筛选 | `deai-course` 公开课 |
| **核心层** | 训练营/系统课程 | 999-5000 | 主力营收 | `deai-course` 系统课 |
| **利润层** | 咨询项目/企业内训 | 1万-10万+ | 高利润、建案例 | `deai-consult` + `deai-course` 内训 |
| **长期层** | 私董会/年度陪伴/合伙人 | 数万+ | 高黏性、长周期 | 口碑转化 |

**产品设计原则**：引流产品（证明价值）→ 核心产品（交付价值）→ 利润产品（高价值深度服务）——**IP 不是一门课，是产品矩阵**。

### Step 5：运营/粉丝/道场/变现系统（怎么持续运转）

| 系统 | 内容 | 关键动作 |
|------|------|----------|
| **运营系统** | 内容排期、平台运营、数据分析 | 每周内容日历 + 数据复盘（联动 `deai-analytics`） |
| **粉丝系统** | 粉丝分层、互动机制、社群运营 | 粉丝分层管理 + 专属福利 + 定期直播互动 |
| **道场系统** | 线下课/训练营/私董会（"聚合能量搞道场"） | 定期线下活动建立深度连接 |
| **变现系统** | 变现路径、定价策略、复购设计 | 引流→核心→利润产品阶梯 + 学员转介绍机制 |

**变现路径（可组合）**：
1. 内容变现：平台分成/赞赏/付费文章
2. 课程变现：公开课→系统课→训练营
3. 咨询变现：企业诊断→项目咨询（`deai-consult`）
4. 生态变现：合作/代言/版权/私董会

```markdown
- 差异化：...

## 二、内容系统（内容金字塔）
| 层级 | 内容类型 | 频率 | 来源 Skill |
| ... |

## 三、流量系统（公域→私域）
- 平台矩阵：{主平台/辅平台}
- 转化漏斗设计：...
- 私域承接：...

## 四、产品矩阵
| 层级 | 产品 | 客单价 | 状态 |
| ... |

## 五、运营计划（90 天）
| 阶段 | 目标 | 关键动作 | 里程碑 |
| ... |

```

## 与 Skill 体系的联动

| Skill | 在 IP 体系中的角色 |
|-------|-------------------|
| `deai-daily-pipeline` | 内容金字塔塔尖的持续产出（深度文章） |
| `deai-video-script` | 塔身短视频/直播切片产出 |
| `deai-course` | 产品矩阵的核心/引流课程开发 |
| `deai-consult` | 利润层咨询项目 |
| `deai-analytics` | 运营系统的数据复盘与选题反馈 |
| `deai-knowledge` | 方法论弹药（网红讲师 IP 方法论等） |
