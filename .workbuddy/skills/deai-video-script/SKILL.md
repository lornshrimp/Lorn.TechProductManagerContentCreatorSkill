# `deai-video-script` — 短视频脚本与直播话术

## When to Use
- 审核通过的终稿需要转为短视频分发（抖音/视频号/小红书）
- 需要为直播准备口播框架（知识型直播/卖课直播）
- 需要将深度内容"切片"为多个短视频选题

## Input
- `drafts/{日期}/{选题名}/终稿-{标题}.md`（母稿——核心信息源）
- 可选：`deai-knowledge` 素材库（`素材库/平台方法论/直播话术框架.md` 等卡片）

## Output
- `drafts/{日期}/{选题名}/视频脚本/短视频脚本-{标题}.md`（短视频形态）
- 或 `drafts/{日期}/{选题名}/视频脚本/直播话术-{标题}.md`（直播形态）

---

## 核心方法论

**短视频不是"把文章读一遍"**。短视频的注意力契约是：3 秒决定看不看，30 秒决定关不关。母稿的深度论证必须**压缩为"一个观点 + 一个证据 + 一个钩子"**的口播单元。

| 维度 | 图文母稿 | 短视频脚本 |
|------|----------|-----------|
| 信息密度 | 全量论证 | 每 60-90 秒只讲 **1 个核心观点** |
| 结构 | 引言→论证→结论 | 钩子（0-3s）→反转/冲突（3-15s）→价值（15-50s）→CTA（50-90s） |
| 语言 | 书面+口语混合 | 纯口播：短句、口语、有停顿 |
| 情绪 | 全篇一条情绪曲线 | 单点情绪爆发（焦虑/好奇/共鸣选一个） |
| 载体 | 纯文字 | 画面 + 声音 + 字幕三重传达 |

### 母稿→短视频的切片原则

一篇 2500-3500 字深度文通常可切 **3-5 个短视频**，每个视频聚焦母稿的一个核心论点：

| 切片方式 | 说明 | 示例 |
|----------|------|------|
| **单点深挖** | 母稿的一个核心观点 → 一个视频 | "AI 涨价"→ 视频1：谁在受益 |
| **反驳切入** | 母稿中的争议点 → 反转式视频 | → 视频2：骂割韭菜的人算错了账 |
| **清单切片** | 母稿中的方法论清单 → 逐条成片 | → 视频3：3 个判断信号 |
| **避坑切片** | 母稿中的反面案例 → 避坑视频 | → 视频4：这些坑别踩 |

## 形态一：60-90 秒短视频脚本

### 脚本结构（4 段式）

```
┌─ 钩子（0-3 秒）──────────────────────┐
│ 第一句话必须制造"不看完就亏"的感觉      │
│ 类型：反常识断言 / 惊人数据 / 悬念提问   │
├─ 反转/冲突（3-15 秒）─────────────────┤
│ 打破认知："你可能以为是 X，其实是 Y"    │
│ 或直接亮出矛盾：现状 vs 真相            │
├─ 价值（15-50 秒）────────────────────┤
│ 核心论证：1 个观点 + 1 个证据 + 1 句金句 │
│ 证据用母稿的真实数据（保留来源）         │
├─ CTA（50-90 秒）─────────────────────┤
│ 引导：关注/收藏/评论"你怎么看"          │
│ 或引导看完整图文（引流母稿）            │
└──────────────────────────────────────┘
```

### 输出格式（分镜表）

```markdown
# 短视频脚本 · {标题}

## 视频信息
- 时长：60-90 秒
- 平台：{抖音/视频号/小红书}
- 选题切片：{母稿哪一段}
- 情绪基调：{焦虑/好奇/共鸣}

## 分镜表

| 时间 | 画面 | 口播文案 | 字幕要点 | 情绪 |
|:----:|------|----------|----------|:----:|
| 0-3s | {场景/视觉} | {钩子第一句} | {大字：核心断言} | 好奇 |
| 3-15s | {场景} | {反转内容} | {冲突对比} | 惊讶 |
| 15-50s | {场景} | {核心论证：观点+数据+金句} | {关键数据放大} | 信服 |
| 50-90s | {场景} | {CTA} | {引导文字} | 行动 |

## 口播全文（纯文本，供配音）
{完整口播文案，200-350 字}

## 封面标题
{≤15 字，含核心搜索词，信息流大图友好}

## 数据来源标注
{母稿中引用的数据及来源，便于视频标注}
```

### 口播写作规则

1. **短句**：每句 ≤15 字，句句有停顿点（口播呼吸节奏）
2. **无连接词**：删掉"首先/其次/另外"，用停顿和画面切换代替
3. **口语化**："说实话""你细品""这个数我第一次看到是不信的"
4. **金句前置**：最有力的那句放在 15-50s 价值段开头
5. **数据可视化**：关键数据要在画面中放大展示（口播+字幕双通道）

## 形态二：直播话术框架（知识型/卖课直播）

### 直播结构（60-90 分钟标准框架）

```
┌─ 开场（0-5 分钟）─────────────────────┐
│ 欢迎 + 自我介绍 + 今日主题预告 + 互动暖场 │
├─ 干货段1（5-25 分钟）─────────────────┤
│ 母稿核心观点 1：讲清 + 案例 + 互动提问    │
├─ 干货段2（25-45 分钟）────────────────┤
│ 母稿核心观点 2：讲清 + 案例 + 互动       │
├─ 干货段3（45-60 分钟）────────────────┤
│ 母稿核心观点 3 + 争议讨论               │
├─ 收尾转化（60-75 分钟）────────────────┤
│ 价值回顾 + 引导关注 + 引流课程/社群      │
└──────────────────────────────────────┘
```

### 输出格式

```markdown
# 直播话术框架 · {标题}

## 直播信息
- 时长：{60/90 分钟}
- 平台：{视频号/抖音}
- 主题：{母稿主题}

## 分段话术（每段含：口播要点 + 互动问题 + 时间控制）

### 开场（0-5min）
- 口播：{欢迎词 + 主题预告 + 利益承诺}
- 互动问题：{1 个暖场问题}

### 干货段1（5-25min）：{观点1}
- 口播要点：{3-5 个要点，每个 = 观点+证据+金句}
- 案例：{母稿案例，可口语化展开}
- 互动问题：{1 个引导评论的问题}

### ...（干货段2/3 同构）

### 收尾转化（60-75min）
- 价值回顾：{3 条干货一句话回顾}
- 引导：{关注 + 评论区互动 + 引流（课程/社群，须合规）}

## 关键金句清单（直播中反复强调）
1. {金句1}
2. {金句2}

## 互动问题池（备选，根据实时弹幕调整）
- {问题1}
- {问题2}
```

## 合规要点（联动 deai-compliance）

1. **AI 辅助声明**：若口播文案由 AI 生成改写（B 级人机共创），平台要求标注时须声明
2. **数字人口播**：若用 AI 数字人（如剪映数字人），须在平台规则允许范围内，并考虑"非真人自动化创作"风险——视频号/抖音对 AI 数字人主播有特殊标识要求
3. **直播带货合规**：卖课直播须遵守平台营销规范，不得虚假承诺收益
4. **数据真实**：口播中的数据和母稿一致，标注来源
